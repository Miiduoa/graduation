# 學校帳號與個人資料匯入

## E校園資料擷取暫停（2026-10-30）

依專案擁有者要求，`packages/shared/src/puEcampusDataPolicy.ts` 目前關閉 E校園資料擷取。
Web、後端與更新後的 App 在發出校方請求前停止登入驗證、課表、成績、學分、個人公告等讀取；
App 的 myPU 課綱更新及 E校園連線檢查也暫停。暫停不是帳密錯誤，不應自動重試、清空快取或把空結果覆蓋既有資料。

已匯入資料與手動檔案／文字匯入保留。既有 TronClass session 的獨立讀取維持原本規則；
需要先經 E校園驗證的學生學號登入與原生統一登入則暫時不可用。

只有擁有者明確要求恢復時，才可修改共用政策並重新驗證、發布。不得在後續功能開發時自行移除暫停閘。
GitHub 上的程式修改必須隨 Web／後端部署與 App 更新才生效；既有已安裝舊版 App 的直連程式不會因提交自動更新。

## 使用者流程

1. 在登入頁確認目前所選校園。學號直接連線目前僅適用於靜宜大學（`pu`）。
2. 靜宜學生可用 e 校園帳號驗證，後端透過既有校務連線建立對應的帳號與本人資料工作階段。課表、成績由使用者登入後透過具備權限檢查的校務查詢功能讀取。
3. 其他校園仍可前往「資料匯入」，以本人取得的課表圖片、PDF 或 CSV 辨識、預覽、修正並確認儲存；此路徑不要求學校與平台合作，也不使用校務帳密。
4. Google 帳號用於平台交流與課班服務，不代表已驗證學籍或取得學校校務權限。

## 邊界與資料安全

- 前端和後端都檢查所選校園，非靜宜學號不得送往靜宜登入端點。
- 對本人資料的校務連線不是學校官方 SSO。請勿以登入成功推定教師、課班或管理員權限。
- 學校系統登入若需驗證碼、多因素驗證或同意規範，不應自動繞過；新增學校前需要針對其實際流程獨立驗證。
- 使用者匯入檔案時必須先預覽與確認，不應將上傳內容自動視為校方認證資料。
- 不支援的校園不顯示學號與密碼表單，避免把帳密送進錯誤的校方端點。

## 驗收

- 靜宜學號登入及返回原目的地、重連與取消、Google 帳號互斥操作。
- 切換學校時清空先前輸入的密碼，不繼承前一校的登入狀態。
- 非靜宜學校僅顯示狀態與可操作的資料匯入替代路徑。
- 確認手機窄螢幕、系統深色模式、鍵盤操作、無障礙狀態提示。
- 通過 `apps/web` 的登入與 Firebase 登入測試、`backend/functions` 的校園登入守門測試，以及完整 lint/typecheck/build 後，才適合部署。

## 不需校方串接的表格匯入（Web／App）

- 適用於使用者**已自行登入學校網站**並取得的資料。從課表、成績頁面將表格複製到 Web 的「原始文字」欄位；瀏覽器若提供 `text/html` 剪貼簿格式，系統會辨識表格並讓使用者選取。
- 也可在學校頁面另存 HTML／HTM，從 Web 或 App 的「選擇檔案」匯入。解析在裝置本機執行，程式碼不會執行檔案內腳本，也不會向學校網站發出新的登入／同步請求。
- HTML 匯入最多 500 KB；支援帶標題欄位的課程／成績資料列，以及含星期與節次的部分週課表（含 `rowspan`）。只能解析實際存在於 HTML 表格中的文字，不能讀取僅由 JavaScript 後續載入、圖片化或跨網域保護的資料。
- 選表格後沿用既有的資料核對、逐筆修正、個人帳號與校園隔離、重複資料防護及確認儲存；未驗證的資料僅是個人參考，**不會**自動變成修課資格或校方成績。
- 沒有中繼代理、爬蟲輪詢、校務帳密儲存或背景登入。因此這是**免校方合作的本人表格匯入**，尚非跨校帳密登入後的自動同步。未來要新增即時同步必須逐校確認使用者授權、登入方式與資料使用範圍。

- HTML 文件會在找到**唯一且明確**的學年度／學期標示時，建議補上尚未填寫的欄位；如果來源含不同學期則不自動推定。這只是參考，使用者仍需逐筆核對及按確認匯入。
