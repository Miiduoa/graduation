# 個人匯入：裝置端視覺辨識與來源核對

這次修改針對課表、成績、活動／考試的匯入，以及課務頁面間的操作路徑。辨識結果先成為個人草稿，使用者核對後才交給既有儲存流程；校方正式資料與課班權限沿用原有流程。

## 使用流程

1. 選擇課表、成績或活動，以及資料所屬校園與學期。
2. 有校務網頁表格時，可直接複製表格、讀取自己保存的 HTML，或使用「從已登入的學校網頁擷取」工具擷取可見表格。只有截圖時，Web 可選「用 AI 讀取截圖」。一般圖片／文件讀取入口仍保留。
3. PDF／XLSX 可選取頁面、工作表與起始列，再按「用 AI 整理選取內容」；沒有固定欄位標題也能交給模型整理已讀取的文字，超出裝置限制時要求分批。
4. 對照來源與每筆欄位。可切換「待修正」或跳到第一筆問題；修正中的資料列會留在畫面，不因輸入第一個字就消失。
5. AI 草稿需要明確勾選已逐筆核對。任何欄位或選取範圍改動，都會重新要求核對。缺少必填欄位或格式錯誤仍無法儲存。
6. 確認後只新增個人紀錄，沿用既有去重、衝突檢查、帳號／校園隔離與批次撤銷。

重新辨識既有草稿會先詢問是否取代。辨識失敗、取消、逾時或回覆屬於已離開的工作區時，原草稿不會被新回覆覆蓋。Web 暫存草稿保留核對要求，重新開啟頁面不會沿用先前的確認勾選。

## 介面與操作路徑

Web 與手機匯入頁以「選擇資料、核對內容、確認新增」安排資訊。來源、可匯入筆數、待修正欄位及儲存位置都在實際操作旁顯示；AI 可疑欄位保留可編輯空值，錯誤訊息直接對應該筆資料。Web 的寬螢幕核對畫面並列來源與欄位，窄螢幕改為單欄；手機提供本次截圖的放大對照。

Web 的課表、成績、學分規劃、行事曆及匯入頁共用課務導覽，保留所選校園，匯入按鈕依所在頁面選擇課表、成績或活動類型。導覽只出現在這五個頁面，不改變帳號與其他服務的導覽。沿用既有明暗主題、字級與色彩，按鈕至少 44 px，鍵盤焦點與目前頁面有明確標示。

手機共用搜尋列補上搜尋欄標籤與 44 dp 的清除按鈕；分段選項補上選取／停用語意及最小觸控高度。這些是實際使用中的共用元件。另修正目前尚無畫面引用的表單 Input：外部 focus／blur 回呼不會蓋掉內部焦點樣式，停用狀態不會被 editable／readOnly 參數覆蓋，密碼顯示按鈕有操作名稱。

## Web：直接把圖片交給視覺模型

| 項目     | 實作                                                                                           |
| -------- | ---------------------------------------------------------------------------------------------- |
| 模型     | `onnx-community/Qwen3-VL-2B-Instruct-ONNX`                                                     |
| 固定版本 | `5dc9194ba42fa62c2f1440d98a71f7cd5280afe2`                                                     |
| 執行環境 | Transformers.js 4.3.1、瀏覽器 WebGPU、背景 Worker                                              |
| 量化     | `embed_tokens`／`decoder_model_merged` 為 q4f16；`vision_encoder` 為 fp16                      |
| 下載     | 約 1.9 GB；僅在使用者明確選擇 AI 辨識後下載，沒有 API key 或按次付費 API                       |
| 圖片限制 | PNG、JPEG、WebP；10 MB、2,400 萬像素內。處理時保留完整比例，縮至最長邊 1,600 px、約 100 萬像素 |
| 工作限制 | 最多 8,192 輸入 tokens、4,096 新生成 tokens；文字來源最多 8,000 字元、回傳最多 80 筆           |
| 取消     | 終止該次獨立 Worker，停止其下載與推論，拒絕晚到結果                                            |
| 快取     | 專屬 `campus-personal-import-ai-v1`；「移除下載模型」只刪除此功能快取                          |

這個入口不呼叫 Tesseract。圖片解碼成像素後直接送給 Qwen3-VL，讓模型讀取表格、星期欄、節次列、課名與跨格資訊；純文字也能交給同一模型整理。

權重、tokenizer、processor 固定同一版本。Worker 的資源請求只允許指定模型檔與本站 runtime 的 GET，沒有圖片或文字上傳端點。截圖預覽只保留於本次畫面；模型權重快取不包含個人課表。

模型不是準確率保證。模糊、小字、錯位儲存格與不規則週次仍可能讀錯。密集整張課表可裁切成較小區塊再匯入。沒有相容的 WebGPU／shader-f16 或記憶體不足時會顯示原因，仍可使用表格、文件與一般文字流程，不會自動轉送雲端。

## 手機 App：本機文字理解與原圖對照

手機使用既有 llama.rn 引擎，僅在實際載入的 Qwen2.5 模型就緒時提供 AI 整理。它處理貼上的文字或既有 OCR 得到的文字，**此版本沒有原生直接圖片視覺推論**。

使用者可進入既有模型管理自行下載與啟用模型。匯入流程不自動下載、不自動啟用雲端模型。為配合目前 4K context 設定，每次最多 1,000 字元、1,536 輸出 tokens；超過限制會要求分批，不會截掉後半部後宣稱完成。

新增 `getLoadedModelId()`，以記憶體中的實際 context 判斷模型身分，避免僅修改偏好就被誤認成已載入。開始與結束時都核對模型身分，來源及校園選項採請求快照。

舊版原生引擎的 `abort()` 不保證立即停止底層計算；本次匯入取消後立即拒絕結果，直到原生工作真正結束前持續占用互斥鎖。介面會顯示模型仍忙碌，不把取消當成運算已釋放。這不等同已完成原生引擎的全面生命週期改造。

本次選取的截圖可在畫面中放大對照，URI 不寫入個人紀錄或備份。換來源、帳號／校園或離開工作區後不沿用舊圖。

## 模型結果的檢查

- 只接受完整 JSON 信封與 `complete: true`；回傳格式錯誤、空結果或超限會保留舊草稿。`complete` 是模型回報，不能當作已讀完全部課程的獨立證明。
- 白名單欄位由應用程式重新建立；模型無法指定帳號、學校、紀錄 ID、課班權限或正式課程連結。使用者已填的學年度／學期優先。
- 文字整理必須附上能在原始來源中找到的片段。允許全半形與空白差異，但保存的是實際原文及正確行號；不接受模型改寫的來源。
- 沒有依據或標為不確定的欄位留空，並指出要核對的欄位。日期、時間、星期、學分、成績與節次仍通過既有驗證。
- 學校特殊節次依原始標記轉換。例如成大的 `N`／`5` 依學校設定轉成正確索引，不將模型給的數字直接當格子位置。
- 圖片結果的片段標示為「AI 辨讀片段」，沒有假稱已與原圖獨立核實。所有 AI 草稿都要求使用者確認。
- 明示日期範圍的全天活動保留不含當日的結束日期；模型漏掉多日結尾時會阻擋匯入，避免變成單日活動。

## 從學校網頁擷取

書籤工具由使用者在自己已登入的校務頁面主動執行，選擇畫面中的表格並下載簡化 HTML，再透過原有校務 HTML 匯入核對。只保留表格文字與必要跨列／跨欄結構，不讀取 cookie、token、密碼欄位，不連線到 Campus One 或第三方，不執行匯入的原網站腳本。

這是一次性的使用者擷取，沒有新增跨校帳密連接器、背景同步或驗證碼處理。校務網站若沒有可讀取的 HTML 表格、內容位於不可存取的內嵌頁面，或禁止書籤程式執行，需改用複製表格或檔案匯入。既有靜宜直連來源仍獨立運作；其他學校不會因此顯示為已支援自動連線。

## 建置與驗證

`apps/web` 的 dev／build 會執行 `scripts/import-ai/prepare-assets.mjs`，從鎖定的 ONNX Runtime 套件複製相符的 `.mjs`／`.wasm` 到本站 `public/ai/onnxruntime/`。生成檔不進 Git；兩份 Web Dockerfile 與建置白名單均包含準備腳本，生成資源隨 Web public 目錄進入映像。腳本檢查 runtime 版本，版本不符時中止，避免默默混用不同版本。無需放寬 CSP 或加入第三方程式 CDN。

實作測試涵蓋模型輸出驗證、來源依據、特殊節次、多日活動、資源白名單、圖片處理、截斷輸出、取消／晚到回覆、模型快取、原生模型身分、草稿保護、核對確認及畫面操作。另已用**實際安裝的 Transformers.js 和固定版本公開 processor/tokenizer**，對人工合成圖片與純文字完成前處理，並驗證模型資源清單全部符合白名單；沒有將 mock 推論當成模型準確率實測。

完整視覺模型的 GPU 生成、不同學校真實截圖的正確率、iOS／Android 真機推論速度與記憶體仍須在適用裝置驗收。此次環境的互動瀏覽器無法存取開發容器 localhost，因此沒有宣稱完成瀏覽器截圖驗收。模型快取可重用，但目前沒有保證網站在無網路下重新開啟仍完整可用。
