校園漫步遊戲用圖（Flux / PIL）
================================
產生方式（專題根目錄）：

  ~/Desktop/AI圖像本地引擎/.venv/bin/python scripts/generate-campus-game-flux.py

離線占位（不需 ComfyUI）：

  …/python scripts/generate-campus-game-flux.py --force-placeholders

真實 Flux 出圖請先啟動 ComfyUI http://127.0.0.1:8188 並勿加 --force-placeholders。

manifest：scripts/campus-game-assets-manifest.json
