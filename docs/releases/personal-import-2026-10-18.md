# 個人匯入與跨裝置同步發布紀錄

日期：2026-10-18。候選版本驗收中；本頁尚不是正式部署完成證明。

## 使用流程

- PDF、XLSX 在裝置讀取，先選工作表／頁面及標題列，再核對資料。單檔 8 MiB、最多 12 張工作表／20 頁 PDF，選取內容合計最多 500 筆。文字、圖片、ICS、JSON 備份入口仍保留。
- 掃描頁會辨識文字；文字標題混合掃描表格的 PDF 可按「重新辨識 PDF 整頁」。取消或失敗保留原預覽；確認前不新增個人紀錄。原檔不會上傳，成績、課表、活動與來源文字只有在使用者同意同步後才傳到帳號。
- 同步需同一平台帳號、同一校園，按裝置開啟。兩台裝置的獨立變更合併；同筆差異逐欄核對。不確定是否成功的寫入需先核對原請求，不能把另一裝置已刪除的資料當作新增。
- 課班比對只用課程欄位，不送整份成績單。使用者核對學校、學期、課號、教師與班別再申請；審核完成且成員資格仍有效才可選取連結。授課者須由不同管理員核對；匯入姓名不等於教師身分。
- 已連結課班可查看伺服器核對資料。失去課班資格後解除連結，但保留個人成績與課表。個人匯入不會改動校方正式紀錄。

| 項目                      | 狀態                                                       |
| ------------------------- | ---------------------------------------------------------- |
| PDF／Excel 實檔讀取與 OCR | 本機通過，多工作表、前導零、中英掃描、混合 PDF、取消重試   |
| Web 建置與完整測試        | 本機通過；同步補強後仍需最後測試                           |
| API 完整來源與資料庫      | 候選已完成 PostgreSQL／兩個獨立 session 驗證；正式部署待驗 |
| Mobile                    | 程式已整合，測試與匯出驗證中；非真機驗收                   |
| 正式 Web／API 發布        | 尚未發布                                                   |
| 正式登入後跨裝置          | 等待使用者在正式站登入；不得以本機測試替代                 |

發布包含最新主線的點餐總開關：正式環境未設定 `ONLINE_ORDERING_ENABLED` 時拒絕點餐寫入；本次不開啟點餐。

API 新增 278／279 migration。舊映像的完整 migration manifest 不相容新 schema，因此回復必須使用以發布前映像為底、包含新增 SQL manifest 的相容映像；不以舊資料庫覆蓋新資料。
