# 成績與學習進度來源

沿用既有資料表與介面，沒有結構異動，也不回寫或修正使用者成績。

| 範圍 | 來源與入口 | 未知與追溯 |
| --- | --- | --- |
| Web 學期成績 | `AcademicPage` 的校方正式資料與讀取時間 | 覆蓋範圍不足會提示缺漏，可回 e 校園核對 |
| Web 課業成績與回饋 | `StudentGrades`；`nuniStudentGrades` 讀取課程介面，`schoolStudentGrades` 讀取既有課程空間與本人提交 | 每筆返回對應作業或測驗；後者是學校課程空間，不冒充正式學期成績 |
| Web 課程進度 | `CourseLearningPath` 組合章節、教材、作業、測驗 | 任一來源失敗、仍在讀取或清單未齊時不顯示完整進度；教材閱讀不算完成 |
| Mobile 學期成績 | `GradesScreen` 的校方成績與既有成績來源欄位 | 顯示來源與公布時間，可查看原始紀錄 |
| Mobile 課內成績 | `CourseGradebookScreen` 的既有課程成績簿 | 待評與缺件各有作業紀錄入口，更新時間無欄位時標示未知 |
| Mobile 課程成績第二版 | `CourseGradesV2Screen`；既有 `grade_items`、本人 `grade_scores` 與 `course_grade_rollups` | 按課程及本人篩選；原始評分項目可開啟；空分數或不完整清單不採用總分 |
| 個人匯入 | Web `PersonalImportSummary` 與 Mobile 個人匯入紀錄 | 顯示個人匯入與匯入時間，原始紀錄可檢視，不視為校方正式成績 |

計分公式：各項分數除以滿分後乘正規化權重並加總，免修排除後重分權重；任一應評項目待評、未取得或滿分無效時總分為未知，班平均與通過率只採總分已知者。

進度公式：已確認繳交或作答項目數／完整取得的作業與測驗項目數；清單或個人紀錄未齊時，完整進度未知。

Web 未讀回饋以來源及帳號分開保存；缺少該來源帳號時不借用另一來源身分。Mobile 原有課程回饋入口不新增未讀保存機制。讀取時間只代表本次核對時間，紀錄更新時間缺少時維持未知。

驗證使用合成資料，涵蓋待評、未取得、明確零分、部分失敗、帳號切換與回饋版本；不連線正式資料庫。回滾可還原本次提交，無需資料修復。
