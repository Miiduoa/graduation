# 本人帳號的展示資料與原功能頁整合

## 目的與介面

依專案擁有者要求，合成資料直接出現在原本的功能頁面，沒有額外的口試或帳號展示工作區。舊 `/demo/account`、`/demo/oral-exam` 轉至設定的「平台權限」，頁尾不再提供口試示範入口。

| 功能 | 使用位置 | 展示內容 |
| --- | --- | --- |
| 學生證 | `/student-card` | 本人展示卡、學號與短效展示 QR |
| 課程與作業 | `/classroom` | 已建立的私人課班、教材、作業、測驗；另有明確標記的合成作業與簽到進度 |
| 成績 | `/grades` | 個人匯入成績與合成作業評分進度 |
| 課表／行程 | `/timetable`、`/calendar` | 同步已配置的個人匯入資料 |
| 點餐與取餐 | `/food` | 固定菜單、確認訂餐、備餐進度與取餐單 |
| 店家 | `/merchant`、`/merchant/workspace` | 本人示範門市、同一筆訂單與可取餐操作 |
| 請假／審核 | `/leave`、`/leave/review` | 申請與審核共用同一筆合成進度 |
| 圖書館 | `/library` | 圖書續借、自習座位預約 |
| 宿舍 | `/dormitory` | A305 檯燈報修 |
| 社群／私訊 | `/community/me`、`/dms` | 合成限動與小組集合提醒 |
| 公告 | `/announcements` | 合成專題成果展示準備會 |
| 權限 | `/settings?section=platform` | 12 個個別開關、全部開啟與進度重設 |
| 助理 | 首頁與 `/ai-assistant` | 明確展示指令、確認卡、保存及讀回；回執直接連功能頁 |

已配置帳號登入後，選擇配置中的校園即可在各頁查看。設定頁的資料權限屬於本人帳號，不要求先選校。沒有有效配置的帳號保留原本功能；真實訂單深連結保留原流程。

## 資料內容

種子工具以管理者在執行時提供的既有 Google 平台帳號為目標，不將私人信箱或帳號識別碼寫入儲存庫。建立 3 門私人課班、6 份教材、6 份作業、3 份簡答測驗，以及 5 筆課表、3 筆行程、3 筆合成歷史成績。既有課班與本人修改保留。

帳號展示設定保存 12 個功能開關與 13 個情境動作的進度，具備啟用狀態與到期時間。餐飲使用固定範例：小日子食堂、香煎雞腿飯 1 份、NT$95、12:10、學生餐廳取餐櫃檯。

第一次使用新裝置，在課表、行事曆或設定按「同步我的課表與行程」。沿用既有同步引擎，不覆寫裝置衝突。使用者關閉權限、登出、換校或離頁後，尚未完成的同步不得繼續套用。

## 狀態與授權

- `GET/POST /api/nuni/account-demo` 由已驗證 session principal 決定平台帳號，不能在輸入指定另一個帳號。
- Web cookie/context 與 App bearer 使用既有驗證；混合驗證來源拒絕。Web 寫入要求 same-origin。
- PostgreSQL 使用 `nuni_account_demos`，RLS 與欄位 ACL 限制 runtime 只能讀取有效列並更新權限、進度及 revision，不能新增配置或延長期限。
- 更新採帳號 row lock、revision CAS、RETURNING 與讀回。停權、過期、版本不符或結果無法確認時不顯示成功。
- 原功能頁共享 `AccountDemoScope`，依帳號、session 與校園重掛。登出、切換、到期、晚到回應、重複點擊與權限撤銷皆有防護。
- 權限開關僅控制本人合成資料。學生證 QR 使用獨立 DEMO 前綴；不授與正式校籍、NFC／門禁、真實店家、付款或全校行政權限。
- 助理只處理明確的「展示／示範／演示／demo」意圖；準備確認卡不寫入。使用者確認後重新核對快照、保存並驗證讀回。模型不能注入展示提議，展示紀錄不加入後續模型 history。
- 一般課表／作業查詢與明確建立個人行程，保留主分支 #595 的原功能。真正 Google AI 寫入權限仍由 #583 處理，本變更不取代該授權。

## 演示順序

1. 用已配置帳號登入，選擇對應校園；在設定「平台權限」確認功能開關。
2. 從原學生證頁出示卡片與 QR，從課表同步個人資料並開啟私人課班。
3. 在原點餐頁確認雞腿飯；到店家工作台標示可取餐，再回原點餐頁查看同一筆取餐單。
4. 在原請假、圖書館、宿舍、社群、私訊與公告頁操作各自的合成資料。
5. 在首頁或助理輸入「查看展示進度」「展示點餐」「展示預約座位」；核對確認卡後保存，使用回執連結回原功能頁。
6. 需要重演時，在設定重設合成進度，原課程與匯入資料保留。

## 驗證與正式發布

資料庫 schema 與個別帳號種子另見 `scripts/demo/ACCOUNT_DEMO_SEED.md`；重跑保留原資料、期限、功能開關及進度。
