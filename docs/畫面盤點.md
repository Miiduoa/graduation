# 畫面盤點：仍走舊站的現役功能

Campus One 已接手未登入進門頁與大部分產品畫面。下列舊站 HTML 目前沒有對等新頁，nuni-web 仍轉發 loopback 舊站，**待新版取代**。沒有替代之前不可從轉發名單拿掉，否則等於刪功能。

| 路徑 | 誰在用 | 狀態 |
| --- | --- | --- |
| `/auth/platform` | 課班／教學入口會經過的平台頁 | 待新版取代 |
| `/auth/platform/class-workspace/join` | 進門頁「課班／教學」 | 待新版取代 |
| `/auth/platform/class-workspace/cw_*` | 加入後的課班工作區 | 待新版取代 |
| `/auth/platform/school-review` | `/admin` 管理台「審核學校申請」 | 待新版取代 |
| `/auth/platform/ops` | `/admin` 管理台「開啟完整管理台」 | 待新版取代 |
| `/privacy/deletion-status` | 商店或刪除回條可能用過的狀態頁 | 待新版取代 |

對照：

- `/auth/account` 已由 Campus One 提供，舊示意卡不再轉發。
- `/auth/find-school` 舊頁改導向新進門頁；找學校改在進門頁內用信箱／校名查找。
- `/auth/account/token`、`/auth/session`、`/auth/platform/*` 端點與登入回調行為不變。
