# 帳號設定、匯出與刪除

2026-10-08。此文件描述程式契約及尚待完成的發布條件，不代表正式環境已部署或完成個資清除驗收。

## 設定與匯出

Web 的一般、帳號、通知、外觀及隱私共用 Campus One 的紙白／墨綠樣式。個人資料與通知的儲存仍須取得伺服器確認；登入方式取自目前帳號，儲存與登出不能重複觸發。

App 匯出只接受明確選取的類別。`expectedUserId` 必須與 callable 的驗證身分相同；校園紀錄與失物招領限目前學校，帳號層級來源可能包含歷史跨校資料。`coverage.sections` 記錄各來源的筆數及上限；多讀一筆確認是否截斷，`truncatedSections` 不為空時不可將檔案稱作完整備份。失敗的查詢不替換成空資料。所選類別沒有 schoolRecords 時，不讀取或附加成績、錢包等校園資料。

檔案以 JSON 保留回傳欄位，分享選單關閉不代表已儲存。Android 接收端可能仍在讀取原始 URI，因此交付給系統分享的快取檔案不會立即刪除；之後的匯出只清理專用目錄中超過 24 小時的同格式檔案，系統亦可清理快取。未交付的中間檔案會移除。原生接收端的實際保存仍待真機驗證。

## 刪除契約

`deleteUserAccount` 需要同一 `expectedUserId`、明確確認及十分鐘內的有效登入時間；不接受非數字、未來或失效的登入時間。回傳成功必須同時包含 `success: true` 與本人 `userId`，App 才會結束流程。這個操作不刪除學校或 Nuni 帳號。

開始前檢查未結款項、群組及店家所有權；需要處理的資料以明確 reason 拒絕。退款同時核對一般來源的 userId 與稽查退款的 studentUid，避免漏掉待人工處理的款項。已取消、現場付款且 paymentStatus 為 pending 的未付款訂單，依既有取消契約可以通過；信用卡、不明付款方式及未結退款不適用這項例外。

清理使用完整文件路徑分頁，不以單獨 UID 查詢 collection-group 文件 ID，也不在 200 筆後停止。群組人數及受控活動名額以交易調整；重試不會再次扣減。讀取、清理、交易及 Auth 刪除錯誤均不回報成功。最後以最小 tombstone 取代個人檔案，確認清理後才刪除 Firebase Auth。失敗時保留刪除中標記及可重試的 Auth 帳號。

明確保留：共享訊息／貼文、作業及評閱、訂單／交易／稽核、舊版活動報名、上傳檔案。財務子集合與個人鏡像也保留。這不是所有資料已刪除或匿名化的承諾；正式保存政策、期限及刪除請求處理仍須確認。

## 權限與部署

Firestore 與直接個人檔案／對話 Storage 存取會檢查帳號關閉標記；群組／學校檔案依清理後的成員關係拒絕存取。Storage 的規則每次只能查兩份 Firestore 文件，因此沒有將額外帳號查詢盲目加到已讀取兩份文件的教學附件規則。參考 [Firebase 跨服務規則限制](https://firebase.google.com/docs/rules/rules-behavior)。文件 MIME 判定現在有實作，測試包含允許 PDF 與拒絕執行檔。

新進入的 index callables 及獨立助理／訂餐／號碼牌／核銷入口檢查帳號標記；刪帳入口本身允許失敗後重試。這是進入操作時的檢查，不是所有已進行中寫入的交易鎖。

匯出及刪帳的 collection-group 索引已列在 firestore.indexes.json。部署必須確認新索引 READY，再開放新版流程。舊客戶端沒有 expectedUserId 時會被拒絕，不能用放寬身分核對解決相容性問題。

`pnpm test:rules` 固定使用隔離的 `demo-campus-security`，與 Storage 規則測試所查的 Firestore 專案一致；其他交易測試各自使用獨立 demo project。新增 accountDeletion.emulator.cjs 已納入 CI。

## 正式發布前仍須完成

- Firebase 資源、帳單授權、正式規則與索引、Nuni／Firebase／Nolu 身分與金流整合。
- 全部既有 HTTP 登入／session、背景工作及已進行中寫入的刪帳互斥；並明確定義重新註冊是否建立新身分，避免重建舊私人資料。
- 在帳號切換期間，既有共用快取清理一旦開始仍無法取消；本批防止後續誤登出新帳號，不宣稱所有快取競態已解決。
- 上傳檔案與共享／教學／交易資料的正式保存與清除政策、期限及可用聯絡管道。公開檔案與既有分享連結不因本次帳號關閉就自動消失。
- 大型資料量的清理期限、錯誤復原操作，以及真實帳號、iOS／Android 實機分享／重新登入與商店驗收。
