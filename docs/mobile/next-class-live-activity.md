# 下一堂課即時動態

沿用 #353 的 `NextClassSnapshot`、App Group 資料橋接、課表變更訂閱與 Widget timeline；沒有另一份時段解析。原本桌面／鎖定畫面小工具保持原有 timeline。即時動態共用同一個 Widget Extension，ActivityAttributes 從本機模組複製到 extension，各自編譯，沒有反向 target 相依。extension 嵌入仍位於 resources 之後、處理 App bundle 的腳本之前。

## 使用方式

啟用 widgets 功能的 iOS 安裝包，可從「我的 → 設定」開啟「下一堂課即時動態」。預設關閉；需使用者主動開啟且系統允許。iOS 16.2 以上提供鎖定畫面，支援動態島的機型另有精簡與展開版。舊系統、缺少原生模組、Android 與 Web 隱藏此入口。系統關閉權限時，仍可關閉已儲存的 App 偏好，只有重新開啟受到限制；畫面提供系統設定入口，並提示仍可在 App 課表查看。

開始範圍為下一堂課上課前一小時至下課，內容包含課名、教室、上課倒數、時段重疊提醒、課程直達及教室搜尋。課程入口沿用快照的課表深連結；找教室會帶入原教室文字與學校 ID，在目前學校地圖搜尋，不把未驗證的教室轉成座標或導航目的地。學校不符或中途切換學校會清除搜尋。

App 啟動、回到前景、匯入或手動改課時，原本快照寫入佇列接著同步即時動態；前景每 30 秒僅重新挑選快照中的下一堂課，不重新載入資料、不連網。相同堂課更新，換堂先結束舊動態再開始新動態。無近期課、快照失效、登出、帳號／學校切換與關閉功能都會結束。舊帳號未完成的讀取不能蓋回清除結果。使用者開關保存在本機，不加入快照，登出清除課程但保留裝置偏好。

## 本機執行限制

**不保證 App 從未開啟時自動產生新動態。** 不需要推播伺服器、付費服務或常駐主機。App 可執行時，以本機計時結束動態並立即移除；下課時間同時設為 ActivityKit 的 staleDate，系統將內容標示過期時，鎖定畫面與動態島只顯示下課提示，移除課名、教室與教室入口。App 被暫停／強制關閉時，本機計時不保證準時執行，staleDate 也不是系統自動結束 API；系統過期畫面的刷新時間由 iOS 決定，不能保證精準到秒。原生模組建立與回前景事件會直接列舉系統既有動態，立即結束已過期或已關閉偏好／權限的項目，不等待課表載入；回前景也會先用記憶體快照核對，再讀取新課表。這些處理仍需 App 取得執行機會。若要保證 App 完全不執行時準時移除，需要另一種系統執行機會或推播，不在本次本機方案承諾內。

過期與結束機制依據 [ActivityKit 顯示與更新文件](https://developer.apple.com/documentation/activitykit/displaying-live-data-with-live-activities) 及 [結束動態文件](https://developer.apple.com/documentation/activitykit/activity/end(_:dismissalpolicy:))。

原生內容不超過 4KB。新原生方法需要新安裝包，正式版 runtimeVersion 為 `campus-one-native-photo-pdf-widget-live-2`，預覽版為 `campus-preview-native-photo-pdf-widget-live-2`；發版腳本、設定契約及建置測試必須一致，舊原生安裝包不應接收這版更新。

## 驗證

合成資料的 Mobile 測試涵蓋：快照轉內容、一小時邊界、上課／下課、過期快照、改教室更新、登出與舊 revision 清除、原生方法缺席、主動開關、系統權限關閉退路、回到前景重查權限、Android／Web 隱藏、教室搜尋的跨校隔離。原生設定測試涵蓋既有／全新 target、重複生成、同一份 Attributes 來源與嵌入順序。

本次修正的相關 Mobile 測試為 6 組／77 項，涵蓋系統禁止時關閉偏好，以及課表讀取未完成時回前景核對動態；原生設定測試為 7 項。Web 地圖測試、發版契約與安全閘門測試另見本次驗證紀錄。

先前已跑過 Expo iOS prebuild（`--no-install`），本次不重跑或下載 Pods。Linux 環境沒有 Xcode／iOS SDK，尚未編譯 Swift 或執行模擬器／實機驗收。

合併前需用既有簽署環境測試：iOS 16.2 無動態島機型與較新動態島機型，各跑開始、改教室、下課、登出、關閉系統權限及切帳號；另測 App 在背景／被強制關閉後的 stale 畫面。確認過期時不顯示教室、兩個連結正確，並檢查完整 Xcode build 沒有循環相依。

## 回滾

關閉 widgets 功能可停止分享並清除動態；單一使用者也能關閉即時動態開關。若需程式回滾，還原本次提交並重建 iOS 安裝包，恢復原 runtimeVersion；不要把含新原生方法的更新送到舊 runtime。已安裝版本的動態需先在 App 中關閉或由系統移除。

## 背景與終止狀態實機紀錄

用合成課程設定數分鐘後下課，記錄安裝包版本、runtime、機型、iOS 版本、預定下課時間，以及以下每項的實際觀察時間與延遲。無動態島與有動態島機型各跑一次，不能以靜態測試取代。

1. 開啟偏好並確認鎖定畫面、動態島與教室連結正常。保持前景跨過下課，確認立即移除。
2. 新建合成課程，回主畫面並鎖屏跨過下課，全程不重開 App；記錄何時轉為下課提示、何時課名教室與連結消失、是否仍殘留動態容器。
3. 重複上一步，但從多工畫面強制結束 App。分別記錄鎖定畫面與動態島，不將 stale 視為已結束。若未準時刷新，記錄仍可見內容與延遲，不宣稱準時清除。
4. 下課後回前景或冷啟動，確認過期動態立即移除；再用離線／延遲課表載入重試，確認清理不依賴新資料返回。
5. 先開啟偏好，再在系統禁用即時動態；回 App 關閉偏好，恢復系統權限並重啟，確認偏好保持關閉且不重建動態。
6. 驗證完整 Xcode build、簽署、extension 嵌入及兩種版型；紀錄測試結果後再決定是否接受本機方案的背景延遲。

`staleDate` 只使內容過期，不排程結束；`.immediate` 只在實際呼叫 `end` 時立即移除，不能先呼叫 `end` 配合未來 dismissal 時刻來維持仍在進行的動態（結束後不再接受更新，動態島也會移除）。本次保留下課 staleDate、可執行時本機計時及原生回前景清理，不承諾暫停或強制結束時準時移除。嚴格要求下課當秒不可見課名教室的情境，仍不符合此本機方案的保證範圍。尚無本次實機結果。
