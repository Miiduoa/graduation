# 共用互動修正與驗收

## 範圍

2026-10-12。以 `main@ce015fdf044e9098e986d0be2d97092670f6bebd` 為基準，修改 Web 共用確認視窗與校園選擇器。不改帳號授權、正式資料、部署設定或原生 App。先前 PR #30 的衝突與業務整合不在這批變更內。

## 修正的行為

- 確認視窗等待非同步操作時，阻止重複送出、Esc、背景點擊與取消；也保留由呼叫端控制的 loading。回應不明不冒稱伺服器已拒絕操作。關閉再開啟後，不接收上一輪的錯誤狀態。
- 共用視窗使用原生 modal dialog 的 top layer 與背景隔離；初始焦點、關閉後焦點返回、巢狀視窗捲動鎖與 Strict Mode 重開皆有處理。確認操作先聚焦取消，而不是直接聚焦破壞性操作。初始開啟狀態不在伺服器輸出 portal。
- 移除確認視窗的大型裝飾符號，保留暖白／深綠主題變數。手機按鈕可換行，關閉控制項 44px，長內容可捲動，標題與操作列不被推離畫面；使用動態視窗高度、安全區與減少動態效果偏好。
- 校園搜尋支援台／臺、全形英數、大小寫及跨名稱／簡稱／代碼的多關鍵字。搜尋不變更目前校園；沒有符合結果時明確標示保留的原選擇。清除搜尋會返回輸入框，選定校園或鍵盤離開後關閉選單；中文輸入組字中的 Esc 不誤關閉。

## 限制與後續驗收

仍需 Safari／iOS 真機、螢幕閱讀器、實際使用此元件的業務流程及正式環境驗收。沒有宣稱完整資安稽核、後端防重複交易或取消已送出的伺服器操作。原生 `showModal()` 不支援的舊 WebView 不提供假模態 fallback；最低支援環境需在發布前核對。

互動基準：W3C APG Dialog (Modal) Pattern；MDN HTMLDialogElement.showModal()。本批不等於完成無障礙認證。
