# 校園導航任務

網頁「校園助理」先讀取所選學校的公開地點，列出實際名稱、分類與別名。使用者確認本次輸入與 Groq 資料範圍後，才送出雲端判讀。模型只選候選編號；既有 `planCampusRoute` 工具重新讀取來源，驗證同校、起終點與座標後建立步行導航連結。沒有距離、抵達時間或無障礙路線的推測。

## 啟用條件

預設不啟用模型。伺服器須同時具備下列合法設定：

- `CAMPUS_AGENT_GROQ_FREE_TIER_CONFIRMED=true`
- `GROQ_MODEL=openai/gpt-oss-120b`
- 既有 `GROQ_API_KEY`
- `GROQ_BASE_URL` 未指定，或為 `https://api.groq.com/openai/v1`

第一項是營運者確認帳戶方案的聲明，程式無法憑金鑰驗證計費方案。模型是待帳戶驗證的免費方案候選，不保證每個帳戶可用，也不承諾無限額度。此變更沒有建立帳戶、設定金鑰、修改部署環境、啟用計費或呼叫正式供應商。

只允許一次 Groq HTTP 請求，20 秒模型總期限；拒絕其他模型、端點與重新導向。429 回報暫時不可用並保留計畫，手動重試；不自動改用 Gemini、Ollama、付費方案或本機推論。

## 資料與執行邊界

傳送內容為使用者當次文字、校園代碼，以及預覽中最多 40 處公開地點的候選編號、名稱、分類、別名。文字輸入仍可能包含使用者自行填入的私人資訊，因此介面要求只輸入地點並在送出前核對；不是自動去識別化保證。不附加帳號、真實地點 ID、座標、課表、作業、歷史對話或私人摘要。

地點文字一律當資料；模型回覆須符合有限 JSON 結構，不能指定工具、網址或任意動作。執行前核對預覽指紋；來源改變要重新預覽。完成後再核對工具回執。查詢時間與來源更新時間分開，目前來源未提供可靠整體更新時間時顯示未知。

任務只讀公開地點，不寫正式資料、不處理付款、訂單、作業或訊息。使用者身分與有效校園成員資格在非同步階段後重新核對。同帳號、校園及請求 ID 的重複執行在單一伺服器執行個體內合併；快取有數量與時間上限，不是跨執行個體的計費去重保證。

取消會停止頁面等待並丟棄遲到回覆；Firebase Callable 沒有傳輸取消介面，已送出的伺服器／供應商請求可能繼續到期限。換帳號、切校園及修改輸入會清除先前同意與結果。

舊 `askCampusAssistant` 自由對話請求會在私人資料預讀與模型呼叫前拒絕，要求新版確認流程。手機舊 callable 收到此特定拒絕時顯示不可用，不因這個拒絕改走其他模型。這是刻意的相容性變更。

此流程不涵蓋網站 `understandCampusRequest` 快捷語意入口、手機其他模型路徑或 Python `/api/agent/chat`。Python 工具確認缺口仍需獨立處理，不能宣稱全端 Agent 的資料與執行權限都已完成。

## 驗證範圍

測試使用合成公開地點、模擬模型 transport 與帳號狀態，涵蓋未同意不送、來源改變、有限計畫、回執核對、配額、逾時、重複請求、撤權與切帳號。瀏覽器驗收使用實際元件、client 與樣式搭配隔離 Callable fixture，不代表已接通雲端、正式部署或真機驗收。
