# 免費方案與遷移邊界

更新：2026-10-12（Asia/Taipei）。

## 成本限制

本專案後續變更以零新增支出為前提。不升級方案、不啟用自動加值、不購買 API 額度、不新增按量收費主機，也不把限時試用當成長期免費方案。遇到免費額度上限時應停止相關操作並清楚標示，不自動改走付費服務。

`.github/workflows/web-release.yml` 已移除 Fly 發布工作，只保留公開儲存庫的標準 Ubuntu runner 本地檢查。該流程不讀取部署憑證、不登入映像倉庫、不推送映像、不呼叫 Fly，也不上傳產物或建立快取。手動執行此流程不會部署網站。

**停用新發布不等於停止既有帳單。** Fly 上的既有主機、Volume、IP、資料庫與其他歷史資源需要另行盤點；這次沒有刪除、停機或取消那些資源。其他工作流程、既有 Actions 產物及整個帳號的費用也不能用本流程的狀態推定為零。

## 免費公車功能

站牌、路線、目的地與座標以交通局官方開放資料為來源；附近距離、站名搜尋及收藏可在瀏覽器處理，使用者座標不必送到收費地圖 API。步行導航透過使用者主動開啟的官方地圖連結提供，不自行把直線距離換算成保證的步行時間。

站牌清冊是靜態參考，不是車輛即時動態。只有來源回覆、資料格式與實際站牌均通過驗證才可發布。公開範例到站檔不能當成即時服務；沒有可靠的免費即時來源時，應提供官方查詢入口並說明狀態。

## 遷移驗收

以已確認的 Netlify Free 作為免費 Web 託管候選，但還沒有建立或發布替代站。Free 的額度用完會暫停服務，不能承諾無限流量。

現有正式站包含 Next.js、新舊帳號相容路由、後端 API 與資料庫依賴，不能只換託管網址就宣稱全站免費。遷移必須先在替代環境核對登入、課程、作業、權限、資料保存、校園切換、交通及原有網址相容性。未通过前不切換正式 DNS，不覆蓋使用者資料，不以空畫面或示範資料代替既有功能。

需要移除舊資源時，應先核對依賴、可恢復的資料與使用者同意的停機範圍，再處理該資源；不能為了省費用直接刪掉承載正式資料的服務。
