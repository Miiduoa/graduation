# Campus One 介面規範

Campus One 保留紙白底、墨綠文字與清楚的列表層次。首頁、校務、課程空間、生活服務與助理使用同一套視覺；助理是服務入口之一，不另設紫色漸層或持續閃動的品牌。

## 現行來源

- Web 色彩、字級、間距與控制項：`apps/web/src/app/globals.css`。
- Web 頁首、頁面寬度與頁尾：`SiteShell`、`AppHeader`、`SiteFooter` 及 `home.module.css`。首頁保留日程版面並共用頁首、頁尾。
- Web 服務名稱與分類：`apps/web/src/lib/campusServices.ts`；服務選單與搜尋共用這份目錄。
- App 色彩、尺寸及陰影：`apps/mobile/src/ui/theme.ts`，畫面透過 `useTheme()` 取得目前模式；子頁沿用共用頁首。

`packages/shared/src/designTokens.ts`、`AI_FIRST_REDESIGN.md` 與未掛載的舊 AppShell 屬於歷史設計，尚未與現行主題同步，不作為新畫面的樣式來源。既有檔案名稱不代表使用者介面需要出現 AI 標籤。

## 色彩與層次

| 用途             | Web token    | 淺色      | 深色      |
| ---------------- | ------------ | --------- | --------- |
| 頁面             | `--bg`       | `#f8f7f3` | `#171f1b` |
| 卡片             | `--surface`  | `#ffffff` | `#202b24` |
| 主要文字         | `--text`     | `#243b35` | `#e5eee3` |
| 次要文字         | `--muted`    | `#626e67` | `#a5b5a6` |
| 分隔線           | `--border`   | `#dddeda` | `#37463b` |
| 主要操作         | `--brand`    | `#314d40` | `#a9c6a3` |
| 主要操作上的文字 | `--on-brand` | `#ffffff` | `#17291d` |

一般卡片使用表面色與細框線，圓角使用 `--radius`。資訊標籤使用次要文字；成功、提醒、錯誤才使用語意狀態色。不能只靠顏色傳達狀態，也不能把不同功能任意分成一排彩色指標卡。

## 頁面結構

1. 共用品牌與主要導覽，不為單一服務另造導覽殼。
2. 一個明確頁名，一句說明現在可以做什麼。
3. 最相關操作與內容優先；次要工具放在內容附近。
4. 載入、來源錯誤、沒有資料、尚未開放分開呈現。失敗提供重試；不能把讀取失敗寫成沒有資料。
5. 共用服務條款、隱私政策及設定入口。

控制項維持至少 44px 觸控高度，焦點使用 `--focus-ring`。列表與表單允許繁體中文、長標題和放大字級換行。服務選單在窄螢幕內捲動，支援 Escape 關閉與鍵盤離開。尊重系統與帳號的減少動態設定。

## 文案與資料狀態

- 使用「查看課表」、「繳交作業」、「查詢館藏」等具體動作；避免 AI 賦能、智慧中樞、全能等宣傳詞。
- 產品畫面不出現 Wave、MVP、資料表、migration 或開發流程說明；必要的設定限制用使用者能採取行動的文字表達。
- 未知營業／供應狀態保持未知；缺乏來源的人數、活躍度、完成率與成果不顯示。
- 操作只有在收到正式服務回應後才能表示完成。等待、失敗與不確定回執保留各自狀態。
- 助理保留資料來源、限制與重要操作確認，不以裝飾性信心百分比替代證據。

## 驗收

檢查 320／390／1365px、淺色／深色、鍵盤焦點、長內容及狀態切換。App 另外檢查已掛載畫面的主題更新與大字級。測試 fixture 只用於隔離驗證，不當成正式資料；版面檢查與單元測試通過，不代表真實登入、部署或商店審查已完成。
