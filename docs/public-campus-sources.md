# 校園公開服務來源與切換準則

## 資料範圍

公開校園偏好僅用來選擇瀏覽對象，不代表學生或教師的校務身分認證。公告、地圖、餐廳、公車及圖書館必須以當前校園識別碼查詢；學校切換時先撤下上一校的資料，再讀取新資料。查詢錯誤、空資料與尚未串接必須各自呈現，不得回退顯示靜宜大學資料。

* 圖書館官方入口維護於 `packages/shared/src/libraryDirectory.ts`，Web 與 App 共用。提供 21 所已查到校方公開網站的連結。
* 只有靜宜 WebPac 的欄位與查詢網址已經核對，支援帶入關鍵字。其他學校僅打開校方官方網站或已確認的館藏目錄；不能冒稱站內即時查詢。
* 借閱狀態、續借、預約及圖書館座位不透過本服務假造回覆。須登入各校官方系統，實際結果以校方為準。
* 靜宜官方館藏與服務：https://webpacx.lib.pu.edu.tw/ 、https://library.pu.edu.tw/
* 清華官方圖書館：https://www.lib.nthu.edu.tw/
* 臺大官方圖書館：https://www.lib.ntu.edu.tw/
* 中興官方圖書館：https://www.lib.nchu.edu.tw/
* 東海官方館藏：https://webpac.lib.thu.edu.tw/
* 各校其他官方網站見圖書館目錄程式碼內的 homepage/catalog 欄位，查核日期：2026-10-14。

## 不可越過的邊界

跨校瀏覽校園服務與個人校務權限不同。切換瀏覽校園不能切換已認證學籍、借書紀錄、學生成績或教師課程；必須各自使用所屬機構驗證流程。沒有官方 API 時不可顯示虛構的即時人數、座位、館藏數量及營業狀態。

目前尚未完成各校對內的 OPAC API 串接、圖資即時數據、所有校園 POI 的實地核對或所有校務系統的正式接入。建立官方連結不能等同已取得校方授權或完成整合。

## 回歸驗證

* 從任一校切換至另一校：網頁標題、圖書館連結、地圖、公告、餐廳、公車資料來源皆需正確。
* `campus=all`、未知校園與目錄故障：不可沿用靜宜資料，須提供選校或重試。
* 同校跨頁導航：保留學校 ID，且不傳遞登入憑證等查詢參數。
* App 代碼切換須清除舊 ID；切換學校後舊關鍵字不能留在新的圖書館頁。
* 未經官方驗證的功能不得顯示已完成或可用的狀態。
