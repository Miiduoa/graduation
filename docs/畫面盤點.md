# nuni 畫面盤點

盤點範圍：`apps/web`（Next.js App Router）與 `apps/mobile`（Expo／React Navigation）。登入、驗證、session、權限、路由守衛、API route、環境變數、Firestore 規則、資料庫與 migration **不在本次處理範圍**。Campus One 登入進門頁與舊站 HTML 轉發見「舊站 HTML 轉發」。

判定：

| 判定 | 意義 |
| --- | --- |
| **A 刪除** | 沒有站內入口或僅剩死碼；或新版已提供同樣功能且舊檔不再被導覽使用。本 PR 刪除。舊網址若可能被書籤則保留 redirect。 |
| **B 已決** | 產品已定案：刪頁／併頁／只調查。本輪依定案處理。 |
| **保留** | 現行產品畫面，有入口且仍在使用。 |
| **redirect 保留** | 舊網址已改成導向新頁，本 PR 維持 redirect、不刪網址。 |
| **待新版取代** | Campus One 尚無對等頁；現役功能仍轉發舊站。沒有替代前不可從轉發名單拿掉，否則等於刪功能。 |

## 舊站 HTML 轉發

先前 nuni-web 用 catch-all `/:path*` 把 Campus One 沒有檔案路由的路徑（含 HTML）轉到 loopback 舊站。這份進門頁清理**拿掉 catch-all**，有新版替代的舊畫面不再轉發、舊網址導新頁；沒有替代的現役功能仍轉發舊站，**待新版取代**。

| 路徑 | 誰在用 | 判定 | 處理 |
| --- | --- | --- | --- |
| `/auth/account` | 未登入進門 | 保留 | Campus One 新頁；舊示意卡不再轉發 |
| `/auth/find-school` | 舊找學校頁 | redirect 保留 | 307 到 `/auth/account`；找學校改在進門頁內用信箱／校名查找 |
| `/auth/platform` | 課班／教學入口會經過的平台頁 | 待新版取代 | 仍轉發舊站 |
| `/auth/platform/class-workspace/join` | 進門頁「課班／教學」 | 待新版取代 | 仍轉發舊站 |
| `/auth/platform/class-workspace/cw_*` | 加入後的課班工作區 | 待新版取代 | 仍轉發舊站 |
| `/auth/platform/ops` | `/admin`「開啟完整管理台」 | 待新版取代 | 仍轉發舊站 |
| `/auth/platform/school-review` | `/admin`「審核學校申請」 | 待新版取代 | 仍轉發舊站 |
| `/privacy/deletion-status` | 商店或刪除回條可能用過的狀態頁 | 待新版取代 | 仍轉發舊站 |

## `/lms-admin` 調查（本輪不改程式）

沒有獨立的 Next.js `/api/lms-admin`。子頁用瀏覽器 Supabase client 在 **page 元件** 裡 `from()`／`rpc()`；layout 用 `RequireAdmin` 包住 children。

`RequireAdmin` 行為（測試已鎖定）：

- **未登入**：顯示「請先登入學校帳號」，不 mount 子頁，不呼叫 `getSession`／`from()`。
- **已登入（含學生）**：永不 mount children；顯示「教學管理尚未完成帳號連結」（或未設定時「教學管理尚未開放」）。不讀另一套身分、不查管理資料。
- 因此學生或未登入直打 `/lms-admin` 及其子頁：**進不到管理內容，也讀寫不到課程／成員／成績彙總等資料**。畫面看得到「教學管理」殼與說明，看不到連結清單與表格。
- 子頁若被掛載，會在 `RequireAdmin` 外層就 `useEffect` 查表；現行 layout 擋住，所以這條路徑現在不會跑。資料最終仍受 Supabase RLS 約束（本輪未改）。
