# 單次調課與一致時段

含資料庫變更：原有按帳號／學校隔離的個人課表文件新增選填 `classExceptions` 陣列。沒有此欄位的舊資料等同沒有單次調整；不刪改既有欄位，不需要 migration。Web 仍依現有政策只寫本機；Mobile 沿用本機與既有個人課表雲端寫入。不新增資料表、索引或背景服務。

課表上方的日期清單顯示實際安排；下方週格保留每週基準。選原上課日期及課程後，可只停一次、改期補課或只換教室。補課可另選起訖日期、時間及教室，最長一天，跨午夜須明填隔天結束日期。重疊可保存，但在保存前與實際課程清單均提示。可用「恢復原安排」移除例外。

`buildPersonalToday` 統一使用台北日期、學校節次表與明確鐘點，輸出起訖時間戳記。Web／Mobile 指定日期課表、今日卡、小工具快照與課前提醒均消費此結果。跨午夜補課會在兩天清單顯示，同一快照與提醒只保留一次。

人工調整獨立於匯入帳本保存，包含原列來源、原上課日期及穩定會次識別。更換匯入批次或列識別碼不會抹除例外。重新匯入改變會次時，無法配對的例外保留並提示待核對，不猜測套用到別堂課。教室來源更新後，人工單次換教室仍優先。每份課表最多保留 200 筆調整，需自行整理不再需要的紀錄。

Mobile 課前提醒由使用者選擇開啟，需通知權限。開啟、前景恢復、課表或匯入變動時，先取消此功能舊通知，再依未來七天的實際課程安排課前 10 分鐘通知，最多 48 筆。關閉、換帳號、換校與登出會清除此功能通知；不取消其他功能的通知。舊讀取／排程請求不得重新填入已登出的通知。沒有背景連線，不保證未開 App 時得知其他裝置修改；七天後需再次開啟更新。未記錄的校方假日與學期終止仍需使用者核對。

## 驗證

使用合成資料驗證單次停課、另日補課、換教室、重疊、跨節、夜間、跨午夜、重新匯入與來源保留、各入口時段一致、通知停用與登出競態，以及舊版儲存呼叫省略新欄位時仍保留調整。通知測試使用替身，不發出真實通知。沒有讀取環境檔、連線正式資料庫或執行 migration。

仍需實機確認 iOS／Android 通知權限、背景與前景更新、登出取消、系統通知額度；iOS 小工具離線／跨午夜／改課後重載與直達課表；兩端日期輸入、深淺色、大字體與小螢幕鍵盤操作。

## 回滾

還原此變更並重新建置用戶端即可；保留文件與本機資料裡的 `classExceptions`，不要刪除使用者的人工調整。舊版只顯示每週基準，不套用日期例外。降版前先在新版關閉課前提醒，確定此功能通知已取消，再移除排程程式；若通知取消失敗，留在新版重試。沒有資料庫 migration 可回滾。
