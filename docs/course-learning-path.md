# 課程學習路徑驗收

範圍：Campus One Web 的 `/classroom/course/{workspaceId}`，使用現有 Nuni 課程 API。此功能不修改校務課表、不建立正式校籍、不取代學校學期成績。

## 教師操作

1. 登入一門自己有教學權限、狀態為 active 的平台課程。
2. 開啟「學習路徑」，建立章節。伺服器回傳新單元後，才顯示已建立。
3. 在「教材」、「作業」或「測驗」的發布表單選擇章節。章節選擇與內容一起送至既有 `class-workspaces/{id}` API。
4. 重新整理後，確認同一門課、同一章節下可看到發布內容；教師可沿用原本的收件與回饋操作。
5. 未分類內容仍可發布，已發布資料不會在建立章節時被自動改寫。

後端目前提供 `units` 列表與新增 API，沒有在此改動中新增章節編輯、刪除、拖曳排序、檔案上傳或測驗自動計分。既有 `position` 為伺服器決定的排序。

## 學生操作

1. 加入同一課程後，在「學習路徑」確認章節與教材。
2. 點選教材進入教材分頁；點選作業或測驗進入相應分頁及指定項目。
3. 完成繳交或作答後，重新整理或回到學習路徑，確認回執計數。
4. 完成數只依本人 `mySubmission`、`myResponse` 判定，不以打開教材、教師已讀、參考期限或第三方資料猜測完成。
5. 所有 `dueAt` 為建議完成時間，不等於停止收件；收件仍以老師操作後的 `state` 為準。

## 必須驗收的失敗情況

- 單元、教材或測驗讀取失敗：顯示失敗與重試；進度不偽裝成零或完整。
- 教材、測驗達列表最多 100 筆：提示清單與進度可能不完整。
- 既有內容的 `unitId` 不在本次列表：仍出現在「其他內容」，不隱藏、不自動改寫。
- 教師選章節後資料被別處移除或帳號切換：禁止使用過期章節 ID；後端必須再次核權。
- 403/404 權限撤回：沿用課程頁既有清除私人資料路徑，不能僅隱藏按鈕。
- API 回應遺失：保留送出內容與冪等鍵，讓老師確認相同一筆結果。
- 行動寬度、鍵盤 Tab／方向鍵與連結焦點：從章節進入原作業、測驗、教材，返回不應遺失未送出的草稿。

## 尚未涵蓋的 LMS 差距

多題型與安全計分、題庫、檔案／影音內容儲存、評分規準與學期成績簿、正式請假審核、課程討論串與跨端即時推播都未由本功能新增。這些流程需要後端授權模型及資料保存驗收，不能以現有課程文字題介面視為已完成。

分支功能需完成 CI、production build、實際登入帳號及瀏覽器跨角色驗收，才有資格合併與部署。PR 開啟不等於正式上線。
