# Campus One 語音 AI 服務接線盤點（2026-10-25）

**本文件僅表示程式碼接線範圍，不代表正式站已部署、校方已授權或實際來源已通過測試。** 目前 PR #218 為 Draft。

## 不同的「接通」層級

- **可導航**：AI 能推薦已存在的網頁服務；目前包含 33 個現有路由。手機某些獨立服務尚無原生畫面，僅會開啟有說明的替代入口。
- **可讀 Campus One 平台資料**：新 API 會在驗證本人與所選學校 active membership 後，透過既有 Firestore/Tool 讀取器取得部分摘要；不代表學校官方系統資料同步。
- **正式校務系統／可完成交易**：尚未全部接通。需各校的正式 API、學籍與校務 SSO 授權，並維持交易前的本人明確確認與讀回驗證。

## 新接的後端只讀摘要

| 入口 | 已核對的程式來源 | 不能推論的資訊 |
| --- | --- | --- |
| /classroom | 已加入、身分驗證通過的 Firestore 課程未交作業 | 未連線的校外 LMS 與已全部完成 |
| /announcements | 已配置的校園公告來源及品質篩選 | 最新校方公告是否全部收錄 |
| /events | 同校活動資料並排除未發布、取消項目 | 報名是否完成、即時名額 |
| /map | 已登錄 POI，只有語句具體指定地點才查 | 未登錄建築、即時步行 ETA |
| /cafeteria | Campus One 登錄的餐廳資料 | 是否營業、是否接受訂單、庫存 |
| /library | 本人 Campus One 借閱資料副本 | **學校官方 OPAC 帳戶借閱狀態** |
| /dormitory | 本人平台內的報修資料（詢問進度時） | 宿舍本機備忘或校方正式受理 |
| /food | 本人本校的訂單副本 | 外部商店或支付渠道訂單 |
| /messages | 使用者帳號通知中屬於本校的資料 | 其他學校、未同步通知 |
| /dms | 本人參與的本校私訊摘要 | 非本人對話與其他人識別資訊 |
| /lost-found | 本校平台公開刊登中的失物案件 | 校方另設失物系統、聯絡人私密資料 |
| /groups | 本人本校有效群組連結數 | 所有學校 LMS 課程是否完整同步 |

失敗與未提供資料不可說成「沒有」。讀取器在切換或撤銷成員身分後，會拒絕顯示先前讀取的私人資料。

## 33 個服務中尚需官方或裝置連線的部分

| 類別 | 服務 | 現有邊界 |
| --- | --- | --- |
| 正式課表 | /timetable | 後端今日課表讀取器明確回傳 unavailable；不能推論明日空堂 |
| 校務／課業 | /import、/appeals、/teacher、/grades、/credit-planner、/grades?tab=feedback | 需要來源學校授權、教師角色、裝置檔案或 Nuni Session；目前只連到原服務頁 |
| 校園生活 | /bus、/clubs、/school-info | 公車需確切站牌 ID 與可驗證的 TDX 資料；其他依學校官方來源 |
| 社群 | /community、/friends | 需使用者登入與同校或好友分享權限，仍由既有介面辦理 |
| 帳號／服務 | /calendar、/merchant、/ai-assistant、/support、/account-deletion、/profile、/settings、/classroom/account、/admin | 本機、Nuni、管理員或敏感帳號操作；不能由 AI 任意繞過權限 |

## 明確需要另外驗證的事項

1. 最終 SHA 的 CI、Web/Mobile 型別與單元測試、Functions、Firestore Rules 和建置必須全部通過。
2. 新的 understandCampusRequest 真正部署於測試環境並使用配置完成的 Groq 或 Gemini 模型；不得將 Jest 模型回覆當作真正的模型驗證。
3. 登入、退權、跨校、跨帳號、封鎖其他人私人資料、無網路與錯誤提示需在實際帳號驗證。
4. iOS Safari 和 Android Chrome 語音權限測試，以及原生 App 鍵盤語音體驗；原生一鍵音訊 SDK 仍未建置。
5. 各校正式資料是否可取得需校方提供介接權限、使用者授權、合法資料來源及可稽核的同步方式。
6. 借還書、繳交作業、付款、請假、報修和重要設定必須有確認、冪等保護與伺服器讀回，不會由一句口語自動完成。

狀態命名請固定使用「Campus One 平台紀錄」、「官方待驗證」、「開啟既有服務」、「來源暫不可用」，不能在資訊不完整時統一標示已接通。
