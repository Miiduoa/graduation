# 找到服務後，能自然接著操作

接續 #735 的操作回饋改版，以 `main 27ad30c0a098908b2161950303fcf9209764a083` 整合上輪介面版本。保留 nuni 現有灰綠配色、五個主要入口和角色權限，集中改善服務搜尋、切換分頁、返回原操作及大字顯示。

## 改變後的使用體驗

| 情境                 | 行為                                                                                                                         |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 手機或放大文字       | 服務選單依面板可用寬度和文字大小改為單欄；搜尋欄與「查看結果」各有完整行寬。相關服務、用途說明和課務標籤一起跟隨字級偏好。   |
| 底部導覽文字換行     | 底欄由內容決定高度，量測包含安全區的整個邊框盒。內容留白、通知、助理與選單共用實際高度，文字和圖示保持完整。                 |
| 今天頁面使用大字     | 依課程與待辦卡片的實際寬度重新排列：時間移至課名上方，繳交及找教室移至正文下方，保留完整閱讀寬度。                           |
| 鍵盤切到長篇備註     | 在對話視窗內以 Tab 進入多行欄位時，必要時微調視窗內捲動，至少露出兩行可讀內容；不改變焦點、游標或外層頁面位置。              |
| 輸入服務後按 Enter   | 開啟完整搜尋結果，保留關鍵字、分類和所選校園。中文組字期間的 Enter、方向鍵及 Escape 先交給輸入法。                           |
| Cmd／Ctrl 點選服務   | 另開分頁時保留原選單、查詢與助理。指定其他視窗、下載及取消的點選同樣保留目前面板。                 |
| 從服務按瀏覽器返回   | 服務選單依來源路徑恢復查詢、分類及已展開的服務。快速搜尋及完整搜尋還會比對原本的完整帳號與校園範圍。 |
| 重新進入同頁或重整   | 服務選單沿用同分頁的來源路徑比對，符合時可展開。 |
| 滑鼠與觸控回饋       | 服務文字保持原位，只有方向箭頭使用短距離位移；按壓以背景交代回饋，當前頁面和已選分類保持清楚。系統與站內減少動態均停用位移。 |
| 助理選到目前所在服務 | 「今天」助理中的站內連結（含同頁錨點）維持面板展開。同一完整網址的連結在啟用後保留焦點，另開分頁也保留原任務。                                             |

## 實作要點

- 沿用基準版的同分頁 `sessionStorage`。服務選單依來源路徑還原。快速搜尋與完整搜尋沿用原本的範圍比對，範圍包含學校帳號、平台帳號、平台工作階段及各入口原有的校園範圍。
- 快速搜尋與完整搜尋依基準版的帳號就緒狀態儲存及還原。登出期間沿用既有行為，後續比對發現範圍不符時清除原草稿。
- 服務選單與頁首助理沿用各自的焦點回移規則。「今天」助理沿用基準版的展開與收合行為，詳見下表。
- 「查看結果」沿用同一個 Next Link，避免按 Enter 和點選連結走不同路由。服務連結自身先判斷點選意圖，避免在父層誤把 Next 的 `preventDefault` 當作使用者取消。
- 底欄保留基礎最小高度，實際大小獨立量測，避免 CSS 使用自己量測出的 offset 造成高度循環。ResizeObserver 監聽 border box；切換桌機或卸載會釋放留白，暫時共存的頁面不互相清掉仍需要的高度。
- 沿用既有文字、配色與動效 tokens，沒有新增套件、改動 API、資料存取權限或角色定位。

| 「今天」助理操作 | 與基準版相同的面板與焦點行為 |
| --- | --- |
| Escape | 收合並停止語音，焦點回到開啟控制項。控制項已卸載時回到面板摘要。 |
| 站內連結（同一完整網址、不同網址、同頁錨點） | 面板維持展開。同一完整網址保留連結焦點，頁面或錨點導覽由路由與瀏覽器處理。 |
| 站外來源與修飾鍵另開分頁 | 原分頁的面板維持展開。 |
| 點擊面板外、切換瀏覽器分頁 | 面板維持展開。 |
| 重新導覽 | 同頁歷史或錨點變更維持展開，登入返回錨點可開啟面板。離開頁面時由路由處理卸載。 |
| 操作面板摘要 | 透過原生摘要切換展開狀態，收合時停止語音。 |

## 驗證

「今天」助理以同一完整網址、不同網址、站外來源、同頁錨點各搭配 Enter、點擊與 Escape，驗證路由接手前的面板狀態、焦點及語音行為。另驗證修飾鍵啟用、外部點擊、切換分頁和同頁歷史變更。

元件回歸涵蓋目前頁／新分頁／被取消的點選、服務選單依路徑還原、搜尋草稿的原有範圍比對、輸入法組字，以及底欄觀察器的尺寸和清理生命週期。

`scripts/qa/interface-design/` 使用實際產品元件及 CSS，帳號、課程資料與 Next 路由是明確的合成邊界。這輪路由邊界使用真正的瀏覽器 history，新增檢查：

- 320px／390px／桌面、淺深色、站內大字、200%文字，以及 **320px＋站內大字＋200%文字** 的組合。
- 逐一量測導覽文字、文字行、圖示與點選區域；確認當前頁標記沒有壓到文字，內容底部留白等於實際底欄高度。
- Chromium 的實際 Ctrl 點選新分頁、目的 URL、Back 返回來源路徑、Escape 清除選單草稿，以及 Enter 搜尋的關鍵字與校園；Cmd 點選另以元件事件回歸驗證。
- 搜尋欄寬度、單／雙欄切換、文字偏好、服務文字 hover 幾何、減少動態與生活服務按壓回饋。
- 今天頁面課名及待辦文字保留至少五個字寬；最大文字組合的時間與操作排列在正文上下方。多行表單的鍵盤焦點保持至少兩行可讀範圍。
- 保留原有表單、確認視窗、短視窗、通知焦點／分頁、操作回饋及錯誤恢復的全部驗收。輸出截圖與來源 SHA-256。

本地瀏覽器受環境 socket 限制，實際瀏覽器結果由既有 GitHub Actions 執行並核對來源雜湊。合成 Chromium 驗收的範圍是 Web 操作與版面，不將它當成 Safari、原生 App 真機或正式帳號驗收。最新候選、測試結果與發布狀態記錄於 #735。

## 設計依據

- [Apple：Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)：清楚的主要區域及切換時的操作接續。
- [Apple：Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：以動效表達回饋，尊重減少動態偏好。
- [Apple：Focus and selection](https://developer.apple.com/design/human-interface-guidelines/focus-and-selection)：清楚呈現目前操作位置，避免沒有使用者操作就改變焦點。
