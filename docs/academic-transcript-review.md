# 成績來源補正與明細核對

## 本次操作流程

以本人學號登入後，前往成績頁，選擇學期，再按中英文科目、班級、修別或成績類型查找。
明細每批顯示 40 筆；使用者點擊匯出才在瀏覽器建立 CSV，內容包含全部符合條件的列，而非只有已展開的列。
來源、讀取時間、部分讀取及非正式成績單的說明保留於檔案中。不額外呼叫校務、不上傳第三方，也不匯出姓名或學號。

## 資料讀取

後端原先只嘗試 `/score_query/score_all.php`、選單轉接與 mypu，沒有使用原生 App 已配置的 `/stu_query/score_all.php`。
本次先嘗試既有 e 校園歷年修課入口，成功辨識後直接採用，使用原本的 HTML 樹解析器與本人 session。
404、暫時連線失敗或無法辨識的頁面才沿用舊入口。明確拒絕、限流或辨識到登入表單時停止，不繼續嘗試其他入口。
已成功讀取的明細不被後續來源故障或空結果取代；不跨來源合併成績，不從回傳的學期數推斷完整性。

這個路徑來自專案既有原生實作，尚未以真實校方帳號重新驗收；不是聲稱校方提供穩定的第三方 API。

## 資料語意

- 數字 0 分、0.5 學分、文字成績與空白各自保留，不以真假值混用。
- 篩選類型是數字／文字／尚未提供，不擅自假設所有學制都以 60 分及格。
- 頁首學分及平均仍按所選學期計算；搜尋與明細篩選不改寫這些合計，畫面明示兩者差別。
- 加權平均與既有通過學分仍是成績推算，不代表畢業學分採計。抵免、重修、系所規則與非學分門檻未由本次實作補齊。
- CSV 防止文字欄位被當成公式執行；保留引號、逗號、換行及原始文字成績。

## 驗證範圍

新增後端真實解析器＋模擬 HTTPS 的來源路徑測試、成績篩選／CSV 單元測試及成績頁互動測試。
既有傳輸測試保留，僅加入新的先行來源與相應請求順序，不刪除原有 Cookie、重導、逾時或回應大小檢查。

本機另以實際核心程式完成 35 項檢查，以實際傳輸程式配合模擬解析器完成 16 項流程檢查；四個 TypeScript 檔語法轉譯通過。
上述本機結果不是完整 Jest、Vitest、App 型別或實體裝置測試。完整測試與建置須以此分支的確切提交結果為準。

發布前仍須以授權帳號核對各學期的原始成績與學分，驗收 iOS Safari 下載、手機版面、鍵盤焦點與輔助使用。
本次不修改正式資料庫、權限、登入開關或部署流程，不宣稱全面超越競品。
