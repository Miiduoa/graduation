# 玩課雲唯讀功能開關

`SCHOOL_LMS_READONLY_ENABLED` 僅由 web 伺服器讀取。未設定、空值或任何非精確 `"true"` 的值都視為關閉；需要恢復功能時，將此伺服器環境變數明確設為 `"true"` 並重新部署或重啟服務。不使用公開環境變數。

關閉時，`/school-lms` 與子頁由伺服器轉址至 `/classroom`；課堂清單的新增連結改為 nuni 課程空間。課務導覽、服務選單、服務搜尋與語音結果都不顯示玩課雲作業與教材入口。`getMyTronClassLms` 在初始化執行環境之前回覆 404，唯讀處理函式本身也會拒絕呼叫，因此不查詢快取、不讀取學校工作階段，也不呼叫學校或轉送服務。開啟時保留原有課程、作業詳情、公告、教材與連線重試行為。

本開關限於 #333 新增的玩課雲唯讀功能，既有課程清單與學校登入各自的控制維持原狀。它不會清除已存在的資料。

## 資料規則與刪帳檢查

#333 對 `backend/firestore/firestore.rules` 僅新增 `/_puTronClassLmsCache/{uid}` 的客戶端讀寫拒絕規則。這是伺服器專用快取；沒有放寬現有資料存取權限，也沒有修改或移除既有使用者資料。伺服器管理端存取不受這條客戶端規則限制。

#333 對 `backend/functions/accountDeletion.js` 僅在依使用者欄位清理的集合清單中加入 `_puTronClassLmsCache`，以 `ownerUid` 比對刪帳者。刪帳因此會額外清掉本人的唯讀快取，不會新增其他使用者的清理範圍；沒有快取時仍沿用既有空查詢流程。關閉開關不應略過這項刪帳清理，以免留下過去啟用期間的快取。本次不修改這兩個檔案。
