# 本機測試環境

用 Firebase 模擬器跑一套跟正式站完全分開的環境，給測試的同學登入、填資料、按來按去。專案固定是 `demo-campus-one`，模擬器以外的地方都連不到，也不會寫進正式專案 `campus-one-tw`。

## 需要

- Node 20 以上、pnpm
- Java 21（或 17），模擬器要用
  - Ubuntu：`sudo apt-get install -y openjdk-21-jre-headless`
  - macOS：`brew install openjdk@21`

## 啟動

```bash
pnpm install
pnpm test-env:start          # 模擬器＋測試帳號＋網頁
pnpm test-env:start mobile   # 另外開 Expo，手機版也接同一組模擬器
```

起來之後：

| 服務 | 位址 |
| --- | --- |
| 網頁 | http://127.0.0.1:3291 |
| Auth 模擬器 | 127.0.0.1:19291 |
| Firestore 模擬器 | 127.0.0.1:18291 |
| Functions 模擬器 | 127.0.0.1:15291 |

紀錄檔在 `.test-env/`。模擬器關掉資料就清空，再跑一次 `pnpm test-env:start` 會重建測試帳號；只想補帳號就跑 `pnpm test-env:seed`。

## 測試帳號

到 `/login` 用學號登入，密碼都是 `campus-test-1234`。測試環境不會去學校驗證。

## 防呆

- `scripts/test-env/env.sh` 寫死 `demo-campus-one`，不是 `demo-` 開頭就停。
- 網頁和手機版開了模擬器模式，但專案不是 `demo-` 開頭，會直接報錯不啟動。
- 只有模擬器模式加 `demo-` 專案時，網頁的 CSP 才放行 127.0.0.1／localhost；正式建置不受影響。
- 啟動時會清掉 `GOOGLE_APPLICATION_CREDENTIALS`、`FIREBASE_TOKEN`。

## 沒接的東西

金流、學校選課與成績系統在測試環境都還沒接，畫面上會照實寫還沒接。
