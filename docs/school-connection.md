# 學校帳號與個人資料匯入

## 使用者流程

1. 在登入頁確認目前所選校園。學號直接連線目前僅適用於靜宜大學（`pu`）。
2. 靜宜學生可用 e 校園帳號驗證，後端透過既有校務連線建立對應的帳號與本人資料工作階段。課表、成績由使用者登入後透過具備權限檢查的校務查詢功能讀取。
3. 其他校園仍可前往「資料匯入」，以本人取得的課表圖片、PDF 或 CSV 辨識、預覽、修正並確認儲存；此路徑不要求學校與平台合作，也不使用校務帳密。
4. Google 帳號用於平台交流與課班服務，不代表已驗證學籍或取得學校校務權限。

## 邊界與資料安全

- 前端和後端都檢查所選校園，非靜宜學號不得送往靜宜登入端點。
- 對本人資料的校務連線不是學校官方 SSO。請勿以登入成功推定教師、課班或管理員權限。
- 學校系統登入若需驗證碼、多因素驗證或同意規範，不應自動繞過；新增學校前需要針對其實際流程獨立驗證。
- 使用者匯入檔案時必須先預覽與確認，不應將上傳內容自動視為校方認證資料。
- 不支援的校園不顯示學號與密碼表單，避免把帳密送進錯誤的校方端點。

## 驗收

- 靜宜學號登入及返回原目的地、重連與取消、Google 帳號互斥操作。
- 切換學校時清空先前輸入的密碼，不繼承前一校的登入狀態。
- 非靜宜學校僅顯示狀態與可操作的資料匯入替代路徑。
- 確認手機窄螢幕、系統深色模式、鍵盤操作、無障礙狀態提示。
- 通過 `apps/web` 的登入與 Firebase 登入測試、`backend/functions` 的校園登入守門測試，以及完整 lint/typecheck/build 後，才適合部署。
