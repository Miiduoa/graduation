# 校園日常流程：2026-10-24 候選驗收

這次補齊失物招領的 Web 操作與 App 恢復流程、較早教材的發現與連結，以及 App 學分頁的讀取與計算。此文件描述本輪候選；發布狀態與實際通過數以 PR 驗證紀錄為準。

| 使用者任務 | 改動與必要行為 |
| --- | --- |
| 刊登、編輯與結案 | Web 可搜尋、查看自己的刊登、編輯及確認結案。Web／App 在送出前保存同一編號的意圖，失去回應時重試或回讀同一筆。清空聯絡方式會實際清除；舊版本的不同修改會衝突。 |
| 中斷後繼續 | 草稿與待確認操作依帳號、學校、物品及動作隔離；切換帳號／學校、離開畫面及舊回應不能清除新草稿。儲存失敗可重試；損毀資料保留原編號，經明確操作後恢復。 |
| 尋找較早教材 | Web 搜尋與學習路徑使用每頁最多50筆的既有 API。App 可搜尋這門課已載入的標題、單元與內容；明確教材連結可分批尋找、取消或繼續。部分載入、撤權、失敗及循環分頁都有獨立狀態。 |
| 查看學分與 GPA | 非空成績不再走到未定義變數；讀取失敗可重試。資料須符合目前帳號及學校。PU 成績只接受伺服器驗證擁有者的連線，拒絕無歸屬快取與原生共用 cookie 的後備。NCHU 讀取也核對目前登入者及憑證擁有者。 |

聯絡方式目前可被所有已登入使用者查看，不限本校；兩端介面依實際規則揭露此範圍。較早的只有 reporterId、未具備 userId 擁有者欄位的紀錄維持唯讀。

GPA 的靜宜百分制換算依[現行學則第25條](https://dorac.pu.edu.tw/var/file/59/1059/img/441/0101.pdf)（2026-02-09 修訂）建立4.3制參考表，並保留本機換算來源。通過／未通過符號不納入平均，數值零分仍計入；GPA 保留各次修課，學分加總另作粗估去重。未知或混用的績點尺度不會注入4.0分母。畢業門檻、重修去重、入學年度與學制仍屬個人參考，完整正式認定須核對學校資料。

重現基本檢查請使用專案支援的 Node22 與既定鎖檔：

```sh
pnpm install --frozen-lockfile
pnpm --filter web test
pnpm --filter mobile test --ci
pnpm --filter functions test --runInBand
pnpm typecheck
pnpm lint
pnpm --filter web build
```

另以本機 Firebase Auth／Firestore 實際服務互測 App 建立、Web 讀取及清除聯絡方式、App 舊稿衝突、新版本修改、Web 結案、App 同狀態回讀及另一帳號拒絕寫入。教材測試使用220筆且每頁不超過50筆的合法資料，瀏覽器證據與原生實機證據分開記錄。

這輪沒有完成全產品驗收。教師數值成績簿發布、結構化測驗、跨端持久學分規劃、其餘私人校務快取的擁有者稽核，以及正式後端、真實學校帳號、裝置與商店驗收仍需繼續。App 教材搜尋目前是已載入頁的課內搜尋。部署、讀屏與真機冷啟動連結不能由本機測試或封裝檢查推定通過。
