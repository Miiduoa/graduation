# 操作回饋與頁面恢復

這一輪接續已合併的 #708、#718，以 `main` 的 `cea4084fff5347b5d3203d9cadb499db439040b7` 為基底。範圍是 Web 共用按鈕、操作通知、頁面恢復，以及實際字型驗收揭露的窄搜尋欄；不改動帳號權限、服務資料來源或原生 App。

## 使用者遇到的問題

- 按下共用按鈕後才插入載入圖示，會改變按鈕寬度並推動旁邊的操作。載入中又與一般停用一樣淡，難以辨認是否還在處理。
- 切換分頁或視窗時，通知繼續倒數；使用者回到頁面前，結果可能已經消失。
- 頁面載入失敗與失效連結只有通用首頁入口，所選校園也沒有被保留。恢復畫面重複標題與說明，缺乏明確主次。
- 使用正確繁體中文字型、320px 窄視窗和 200% 文字時，快速搜尋輸入欄被提交按鈕擠到 63px。

## 設計與實作

| 操作           | 改變後的體驗                                                                                                                                                          |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 按鈕載入中     | 保留原文字與左右圖示，底部細活動線不參與排版；保持對比，阻止再次送出，提供 `aria-busy`。只有 `loading` 改變時不會擠動相鄰控制項；呼叫端若改變文案，仍依實際文字排版。 |
| 減少動態       | 載入線改成靜態提示；系統與站內偏好均適用，無需等待動畫結束才能繼續操作。強制色彩模式保留可辨識的邊界與忙碌狀態。                                                      |
| 切換視窗與分頁 | 頁面可見且視窗有焦點時才消耗通知閱讀時間；回來後接續剩餘時間。背景新增的通知保留完整時間，滑鼠停留與鍵盤閱讀仍各自暫停。                                              |
| 較大文字       | 通知標題、內容與圖示使用站內文字設定；關閉鍵保留 44px，維持窄螢幕換行與底部導覽間距。                                                                                 |
| 窄視窗搜尋     | 搜尋欄依元件可用寬度與文字大小換成上下排列，輸入與提交各保留完整一行；不縮小字體或觸控目標，一般寬度維持並排。                                                        |
| 頁面失敗       | 一個明確標題、簡短說明、重新載入與對應服務入口。失效連結以返回入口為主；載入失敗以重試為主。                                                                          |
| 恢復原本脈絡   | 依目前區域返回課務、生活、交流或我的；根頁提供另一個已知入口。沿用目前所選校園，不轉傳私人查詢、session 或任意返回網址。今天與搜尋失敗時也不提供原地繞圈的替代入口。  |

保留 nuni 現行灰綠配色、系統字體、深色模式與五個主要入口。動畫只負責表示仍在處理，不模擬百分比或成功結果。

實際瀏覽器字型紀錄顯示：Linux 已安裝 Noto CJK，但原字型清單只有 `Noto Sans TC`，中文字落到 WenQuanYi Zen Hei。補入套件真正的 family 名稱 `Noto Sans CJK TC`，讓有安裝字型的裝置使用台灣繁體字形；Apple／Windows 的既有系統字型仍優先，沒有新增網路字型下載。

## 驗證方式

- 元件回歸驗證內容不重掛載、圖示與可讀名稱、重複送出、重新操作、通知各自期限、背景新增、失焦／可見狀態順序、清除與卸載。
- 頁面恢復驗證五個目的區域、校園更新、不限校園、查詢參數白名單、根頁不繞圈以及明確重試。
- 既有 `scripts/qa/interface-design/` 使用真實產品元件與樣式；只替換帳號、網路與 Next 路由邊界。新增載入前後幾何比較、恢復入口、實際瀏覽器前景切換與文字偏好檢查。
- 瀏覽器情境沿用桌機、390px／320px、深色、200% 文字、站內大字及兩種減少動態設定；輸出截圖與來源 SHA-256，另檢查強制色彩。
- 真實視窗驗收使用可容納桌機的 Xvfb 顯示範圍，整個情境關閉 Playwright 強制頁面持續有焦點的模擬，讓切換分頁及 Tab 進入瀏覽器列的紀錄反映原生焦點；產品事件與計時器不替換。
- 正式 Next build、Web TypeScript、ESLint、格式與 UI design gate。精確 head 的實際結果以本輪 PR 與 Actions 為準。

本機 Chromium 啟動受 `socket() Operation not permitted` 限制，瀏覽器檢查由 GitHub Actions 執行。合成資料的元件驗收不等於正式帳號操作或 Safari、iPhone、Android 實機驗收；沒有將其描述為正式站已上線。

## 設計依據

- [Apple — Motion](https://developer.apple.com/design/human-interface-guidelines/motion)：讓動效清楚表達狀態與操作回饋，並尊重減少動態。
- [Apple — Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：保持文字可讀、控制可操作與不同輸入方式的一致性。
