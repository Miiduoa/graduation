## 鎖定規格與本次交付（Spec PR 1，唯讀）

以 `/workspace/shared/specs/職涯-規格-v1.md` 為準。不做個人 104 追蹤器，也不做公開履歷、投遞或新權限的寫入介面。

nuni 的差異是先看本校資訊：生活 › 職涯提供「接下來」、校內工讀與實習的真實空狀態、職產處與系所公告、附近職缺補充及官方外連。訪客與登入者完全相同，不要求登入才能讀公開資料。

1. 時間軸混排職產處、資管系與校園徵才的公告標題中明確標示的截止日／活動日期，最多 5 筆、每列 56、日期欄 52；7 日內用主色加粗，點選開啟 Google 日曆確認。只採單一、含年份的明確日期，避免把發布日或模糊日期冒充期限；沒有日期時誠實留空。
2. 靜宜職產處採 HTML 公告轉接（RSS 不採用），系所先接資管系。只回傳標題、公告日期、原文連結與來源標籤，不抓文章正文、不寫 Firestore。其他學校保留原有官方職涯入口，不套用靜宜公告或沙鹿職缺。
3. [台灣就業通政府開放資料](https://data.gov.tw/dataset/44062)以 `zipno=433&count=10` 查沙鹿，僅顯示職稱、公司與原頁連結，每筆標示「台灣就業通」。[官方介接文件](https://free.taiwanjobs.gov.tw/webservice_taipei/A17000000J-030144-Taiwanjobs-OpenData.pdf)列明郵遞區號查詢。這些外站機會不代表校方推薦或可抵學分。
4. 各來源各自降級；台灣就業通失敗顯示鎖定句「暫時讀不到台灣就業通的職缺。」不影響校方資訊。校內機會固定顯示「職產處還沒在這裡上架工讀或實習。」及既有官方職涯入口。
5. 104、Cake 只有「到 104 找更多」「到 Cake 找更多」外連，未擷取任何內容。競品比較中的跨平台整理判斷只供背景，這次不做個人追蹤工作區。

## 角色與後續界線

學生、訪客、職涯承辦與平台營運皆可讀公開資訊及回到原文核對；沒有學生案件、審核、名冊或跨帳號紀錄。沒有新增集合、career_staff、careerApplications 或 internshipRecords 寫入，沒有登入／權限／migration 變更。Spec PR 2 的校內工讀申請、課表衝突、權益確認與承辦工作台，以及 Spec PR 3 的實習學分進度均未實作；未來須另行取得「上」。諮詢只回校方網站，不假裝已完成預約。

## 風險與驗證範圍

HTML 結構異動會影響公告解析；上游連線失敗時顯示狀態與官方連結，沒有示範機會。公開資料回應快取最長 15 分鐘，原文才是最終依據。時間軸不宣稱完整涵蓋所有系所與公告正文內的期限；無明確日期不猜測。日曆開啟的是外站編輯畫面，須由使用者確認儲存，不存取行事曆或自動發通知。手機資料透過同一版網頁的 `/career/data` 讀取，須先部署網頁才能讀到新服務。
