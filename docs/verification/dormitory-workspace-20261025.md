# 宿舍工作區：功能範圍與驗證

更新：2026-10-25

## 提供的功能

| 工作流程 | Web | App | 資料來源 |
| --- | --- | --- | --- |
| 瀏覽所選學校的住宿單位 | 有 | 有 | 校方官方網站，未知學校不猜 |
| 宿舍、房間、床位備忘 | 有 | 有 | 自行輸入 |
| 設備問題新增、編輯、分類、狀態追蹤 | 有 | 有 | 自行輸入，非學校受理 |
| 問題說明交接 | 複製 | 系統分享 | 使用者可手動送交校方 |
| 申請、入住及退宿準備清單 | 有 | 有 | 個人勾選，非正式申請 |
| 洗衣預估倒數 | 有 | 有 | 手動計時，非機台即時資料 |
| 帳號及校園隔離 | 有 | 有 | 各自裝置儲存分區 |
| 另一分頁/操作覆寫防護 | 保存前比對 | 寫入前比對 | 當前裝置版本 |
| 校方正式線上申請、繳費、包裹、報修 | 無 | 無 | 未授權存取校務 API；提供官方入口 |

## 設計和資料邊界

- 沿用原站色票、字級與 OLED 深色主題；小螢幕支援、44px 操作範圍。
- 操作以使用者任務為主，避免虛構的空位、報修成功或繳費數字。
- 學校登入狀態不代表已獲住宿資格；個人問題手動設為「已通報」不代表校方受理。
- Web localStorage / App AsyncStorage **只在各自裝置內保存，沒有跨裝置同步**，不宣稱備份成功。
- 訪客、Firebase 使用者及所選校園使用不同的分區。Web 平台帳號也另外分區。
- 顯示空資料、失敗、重試、防覆寫和官方入口狀態，不用示意數據掩飾未完成整合。

## 驗證範圍

本 PR 新增和更新共享資料模型、Web 工作區操作、生活目錄搜尋與 App 導覽測試。

本機如有完整工作區，可執行：

    pnpm --filter web typecheck
    pnpm --filter web test --run
    pnpm --filter web lint
    pnpm --filter web build
    pnpm --filter mobile typecheck
    pnpm --filter mobile test --runInBand
    pnpm --filter mobile lint

**尚須實機驗收：** iOS/Android 鍵盤與安全區、放大字體、螢幕閱讀器、背景切回、官方網站開啟、Web 無痕模式。此文件不宣稱 CI 已通過，以 Pull Request 的 Checks 為準。

## 校方正式系統後續

正式入住申請、床位與繳費、包裹物流、線上報修回執、洗衣機空位與跨裝置同步，需要正式 API、資料分享授權、權限與個資治理。這次均不虛構成果，也不替校方完成申請。
