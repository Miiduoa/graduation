# 課表編輯與課業接續

本輪基於 `main 15bdca30796646d93263ddf8442eca248aa196b4`。將課表編輯、查看課業與動態偏好視為同一條操作流程，沿用 nuni 的配色、原生對話視窗和既有權限。

## 修正的使用情境

| 情境 | 這輪的行為 |
| --- | --- |
| 編輯課程後開啟作業與教材 | 有修改時先詢問「放棄修改並開啟課業？」；繼續編輯或 Escape 保留內容，焦點回到原連結。 |
| 課名被改寫或暫時清空 | 既有課程的課業入口仍根據已儲存的原課程建立；放棄修改後不會搜尋被放棄的新名稱。新課程沿用草稿名稱搜尋。 |
| 沒有修改、另開分頁 | 沒修改時沿用 Next Link；Cmd／Ctrl／Shift、中鍵及其他目標視窗保留瀏覽器行為，原頁草稿不被關閉。 |
| 課表儲存中 | 同分頁課業導覽被阻止，欄位保持不可編輯；儲存失敗恢復操作，不暗中排入跳頁。 |
| 本週到期的測驗與考試 | 依任務類型使用與實際卡片一致的錨點，作業、測驗與考試都能到達目標。 |
| 同頁返回或重選同一任務 | 本週、教材、作業捷徑與任務連結接續閱讀焦點；背景更新不重新奪走正在編輯的焦點。 |
| 開啟減少動態 | 匯入預覽、作業／測驗的下一份回饋、公車結果，均在動作當下讀取系統與站內設定，改成立即定位。 |
| 手機、大字或短視窗 | 課程欄位與提示跟隨站內字級；雙欄依可用文字寬度重排，按鈕可換行，原生視窗保留單一捲動區。 |

## 實作判斷

離開確認只攔截會取代目前分頁的操作。另開分頁不會破壞原編輯器，因此不要求放棄草稿。既有課程的目的地與是否為既有課程，使用相同的已儲存課程查找結果；這避免把放棄後的操作交給草稿值。

課業落點記憶只在網址 hash 改變時重設，資料重新讀取不會觸發重設。再次啟用相同 hash 沒有原生 `hashchange`，由連結補上定位與焦點，同時保留原生網址與歷史行為。

程式式平滑捲動不能只依賴 CSS 關閉動畫。共用 `preferredScrollBehavior()` 每次讀取兩種減少動態偏好，任一要求減少動態就明確使用 `instant`，避免 `auto` 繼承捲動容器的 `smooth`。原本的定位方向、座標計算與 `preventScroll` 焦點交接保持一致。

## 驗證與範圍

- 課表、移動及導覽：3 個檔案、69 項行為測試。
- 課程頁與課業落點：2 個檔案、40 項行為測試；新增案例曾在修改前重現失敗。
- 捲動偏好、匯入、作業、測驗與站牌：5 個檔案、203 項測試。
- 針對修改檔案執行 ESLint；既有 effect 警告未算成本輪新增問題。
- 既有 `scripts/qa/interface-design/` 新增課程編輯情境：實際元件、CSS、原生 dialog、真實 Ctrl 新分頁、短視窗 Tab、明確放棄後才離開、儲存中的 Enter 防護，以及同步量測減少動態時的定位。
- 8 組既有尺寸與偏好涵蓋 1440px 桌機、390px／320px 手機、淺深色、系統或站內減少動態、大字與 200% 文字。截圖、檢查結果與來源 SHA-256 由工作流保存。

瀏覽器驗收使用明示的合成帳號、課程資料及 Next 路由邊界，不進行正式資料寫入。它驗證 Chromium 的互動與版面，不代表 iPhone Safari 或原生 App 真機驗收。

本機全專案 TypeScript 檢查曾遭執行環境終止（exit 137），因此完整型別檢查、建置與其他整合閘門以本輪提交的 GitHub Actions 結果為準。來源分支上的變更不等於已合併或已部署；最終提交與合併狀態記於對應 PR。
