# 本機測試環境

用 Firebase 模擬器跑一套跟正式站完全分開的環境，給測試的同學登入、填資料、按來按去。專案固定是 `demo-campus-one`，模擬器以外的地方都連不到，也不會寫進正式專案 `campus-one-tw`。

## 需要

- Node 20 以上、pnpm
- Java 21（或 17），模擬器要用
  - Ubuntu：`sudo apt-get install -y openjdk-21-jre-headless`
  - macOS：`brew install openjdk@21`

## 啟動

```bash
pnpm install
pnpm test-env:start          # 模擬器＋測試帳號＋網頁
pnpm test-env:start mobile   # 另外開 Expo，手機版也接同一組模擬器
```

起來之後：

| 服務 | 位址 |
| --- | --- |
| 網頁 | http://127.0.0.1:3291 |
| Auth 模擬器 | 127.0.0.1:19291 |
| Firestore 模擬器 | 127.0.0.1:18291 |
| Functions 模擬器 | 127.0.0.1:15291 |

紀錄檔在 `.test-env/`。模擬器關掉資料就清空，再跑一次 `pnpm test-env:start` 會重建測試帳號；只想補帳號就跑 `pnpm test-env:seed`。

## 防呆

- `scripts/test-env/env.sh` 寫死 `demo-campus-one`，不是 `demo-` 開頭就停。
- 網頁和手機版開了模擬器模式，但專案不是 `demo-` 開頭，會直接報錯不啟動。
- 只有模擬器模式加 `demo-` 專案時，網頁的 CSP 才放行 127.0.0.1／localhost；正式建置不受影響。
- 啟動時會清掉 `GOOGLE_APPLICATION_CREDENTIALS`、`FIREBASE_TOKEN`。

## 沒接的東西

金流、學校選課與成績系統在測試環境都還沒接，畫面上會照實寫還沒接。

## 群組提問的助理回覆

- 助理回覆只由 Cloud Functions 的 `groupQuestionAssistantReply` 寫入（提問建立時觸發），寫在 `groups/{groupId}/posts/{postId}/comments/assistant`。
- 用戶端（任何版本的 App）都不能寫助理回覆；舊版 App 會試著自己寫，會被規則擋下，畫面不會報錯，提問照常送出。
- 回覆寫好之前，提問底下顯示「助理回覆中」；一分鐘內沒回覆（或伺服器記成沒辦法回答）就改成「助理暫時沒辦法回答，可以等其他同學回覆」，不會一直轉。
- 畫面上只把伺服器寫的那一則（`comments/assistant`、`generatedBy: server`）當成助理回覆；其他自稱助理的留言（例如上線過渡期舊版 App 寫的）不顯示。
- 網頁目前沒有群組留言畫面，這部分只在手機。
- 本機模擬器沒有設定模型金鑰時，會用伺服器端校園助理的內建回覆；要整個關掉，啟動 Functions 前設 `GROUP_ASSISTANT_REPLY=off`，提問會記成 `assistantReply.status = unavailable`。

## 上正式環境的順序（這裡不做部署）

這一批規則要跟 Functions 一起上，**一定要先部署 Functions，再部署規則**：

1. 先上 Functions（`groupQuestionAssistantReply`）。這時舊規則還允許用戶端寫助理回覆，伺服器也會寫，最多短暫出現兩則。
2. 確認新提問底下有伺服器寫的 `comments/assistant`。
3. 再上 `firestore.rules`。反過來先上規則的話，在 Functions 上線前，新提問都不會有助理回覆。
4. 老師工作台改成只看自己有教的開課：上規則前要先在 `schools/{schoolId}/courseTeachers/{課名｜老師}`（例如 `資料庫｜王老師`）建好 `teacherUids`，不然老師會看不到任何申訴。同名但不同老師的課是不同的文件。
5. 送申訴的課一定要在學生自己的課表裡：規則看 `users/{uid}/personalTimetable/current` 的 `courseIds`、`offeringIds`。新版存課表時會一起寫；舊的課表在送申訴前會自動補上。沒有開課代號（`offeringId`）的舊申訴只有學校管理者看得到。
7. 申訴狀態要看這門課有沒有對應老師：學生端呼叫 `appealTeacherStatus`，只拿到每個開課代號 true/false（只查自己課表裡或自己申訴過的課，看不到老師是誰）。沒有對應、函式還沒部署或叫不到時，一律顯示「這門課還沒對應老師，申訴暫時只有學校看得到。」
6. 婉拒過的好友邀請七天內誰都不能刪（婉拒的人要擋對方改用封鎖），所以對方刪掉也不能馬上重送。
