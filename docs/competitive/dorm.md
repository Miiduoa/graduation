# 宿舍工具競品與實作決策

研究日期：2026-11-14。研究範圍是公開網頁與官方操作說明，未登入校務系統、未加入私人 LINE 群；以下缺口是公開流程的觀察，並非宣稱所有學校都缺少這些功能。

## 1. 清大住宿組網站與服務中心

來源：[新生專區](https://sthousing.site.nthu.edu.tw/p/412-1254-22866.php?Lang=zh-tw)、[服務中心業務調整](https://sthousing.site.nthu.edu.tw/p/406-1254-290396,r8958.php?Lang=zh-tw)。

做得好：把入住、修繕、包裹及生活資訊放在官方入口；服務中心有明確業務分工。做得不足：公告會改變領件地點與時間，學生仍需自己把公告轉成生活安排。公開網頁不能替學生保存已確認的取件待辦。

nuni 要勝出的地方：保留各校官方入口，在包裹頁就能回到校方查證；保留領件地點與自訂取件日；行事曆匯出留待後續。不得把個人輸入顯示成收發室即時資料。

## 2. 興大宿舍報修系統與官方 LINE 宿網窗口

來源：[宿舍 FAQ](https://www.osa.nchu.edu.tw/osa/dorm/qanda.html)、[暑宿公告內的男宿網路官方 LINE](https://www.osa.nchu.edu.tw/osa/dorm/sys/modules/tadnews/index.php?nsn=2016)。

做得好：設備報修由正式系統受理，網路問題另有熟悉宿網的人員；FAQ 說明不同類別的修繕時間與例外。做得不足：入口、網路窗口及後續詢問分散；「問 LINE」本身不等於設備正式報修，也沒有跨窗口的個人紀錄。

nuni 要勝出的地方：沿用既有依學校、宿舍和設備分類的正式交接，補上可聯繫時段、追問日期與自行記下的聯繫紀錄。複製時一併帶出必要資訊，避免反覆重講；已修好可以重新開啟備忘。追問日是自己安排，不能套用另一校的處理承諾。

## 3. 臺大太子學舍會員包裹服務

來源：[會員服務說明](https://ntudorm.prince.com.tw/Member_Login.aspx)。

做得好：住宿中會員可查包裹收件時間、編號與貨號，這是 nuni 沒有校方 API 時不能取代的能力。做得不足：服務限該學舍會員，並非跨校的生活待辦工具；公開說明未提供把個人包裹、報修追問、繳費及退宿日期一起安排的流程。

nuni 要勝出的地方：明說官方查件需回校方管道，不仿造包裹清單；後續可把個人待領紀錄、報修追問和重要日期整理成可匯入行事曆的提醒，保留原有洗衣計時、房況點檢與入住退宿清單。

## 鎖定規格調整（學生端第一個 PR）

以 `/workspace/shared/specs/宿舍-規格-v1.md` 和需求補充為準；上方行事曆方案僅為競品研究提案，本 PR 未納入。入住點檢照片／PDF、外宿與室友組合也不在本 PR。

本次實作改為在原有 Dormitory / DormWorkspace 接上 `schools/{schoolId}/packages` 與 `repairRequests`，只查目前 Firebase 使用者的 `recipientId`／`userId`，不查其他學生、不讀 legacy 根集合、不使用 demo source。兩端使用即時監聽，離開、換校或換帳號時解除。

學生能看到真實包裹的到件時間、品名／寄件人、領取地點；三天未領顯示「明天起退件」。郵局與掛號資料不混入宿舍包裹，另列「行政大樓收發室／掛號包裹請看收發室公告」。領取碼是本人的學號、姓名（34pt），不是密碼，也不會由畫面假裝核銷；讀不到資料時請出示學生證。原本手動紀錄保留在下方「我自己記的」。

今晚宿舍使用同一份雲端包裹、報修與既有洗衣倒數；沒有可讀取的點名／外宿來源就不補假資料。讀取失敗和真正空清單分開呈現。雲端狀態只顯示既有紀錄能證明的時間，沒有時間不拿現在時間補值。所有學生畫面移除舊修繕參考編號，也不在複製內容包含編號。

既有 packages 登錄 callable 已呼叫 sendPushToUser，本 PR 不建立第二套到件推播；也不承諾未部署的職員流程已能登錄。實際到件推播仍依既有服務人員登錄與裝置通知設定。

權限盤點：目前 `repairRequests`／`packages` 已允許本人讀取，無須改規則。`updateRepairStatus` 仍限定 repairs 服務角色，學生端不能直接重開／結案；`settings` 只能學校管理員讀取，未找到既有學生可讀的開通名單。這些是後端實際缺口，不能用本機改狀態冒充雲端成功；需先確認來源或另案取得明確授權。本 PR 不新增 dorm_staff、serviceRoles、集合、ACL 或 migration。輔導員工作台另開 PR，需負責人說「上」。
