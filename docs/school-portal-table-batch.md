# 多表格校務核對

基於已合併 PR #290 與 #315 的主線，補上同次擷取包含多張課表／成績表時的批次核對。不是另一個瀏覽器或匯入資料庫。

## 使用方式

本人同意並在校方頁面登入 → 主動讀取 → 一次核對多張表格 → 選取需要的表格，逐表確認缺省學期 → 合併預覽 → 逐筆修正／選列 → 一次確認儲存，或進入既有重複與更新核對。

- 不預選任何表格。各表獨立解析原始欄名，按來源順序合併；不同欄序不會直接拼接為一張 CSV。
- 學期輸入是原表沒有該欄位時的備用值。原列已有學年度／學期則保留；缺值仍是可修正的錯誤，不從相鄰表格猜測。
- 不同學期的同名課程保留各自紀錄；跨表重複來源也不先刪除，交由原本核對與 ledger 去重。
- 每列附來源表號及該表原始文字行號；保留 rawText。只替草稿 ID 加上表格 namespace，並同步重映射 issue.rowId。
- 最多 12 張表，沿用合計 200,000 字元、500 筆上限。找不到來源、空表、超限不回傳前半段成功資料。表格結構、跨校及未填欄位錯誤不放寬。
- 保留取消、重選、單表匯入、逐筆修正、重解析確認、返回瀏覽器、儲存重試與帳號／校園隔離。選表與預覽不寫入；沒有新增網路、Cookie、帳密或背景讀取。

## 驗證與界線

新增核心與 React Native 整合測試，專項 CI 在原有全部案例之外額外執行。所有結果須綁定最新提交；語法轉譯不等於完整型別檢查或真機驗收。

只涵蓋本次頁面已讀到且本人選取的表格，不代表所有歷年學期完整，不會自行翻頁或繞過校方登入。UI 保留主題變數、checkbox 狀態、44px 以上控制項與自然換行；iOS／Android 真機鍵盤及大型字型尚需驗收。本次沒有新增跨校登入連接器、背景同步、推播或小工具。
