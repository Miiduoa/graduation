# 成績待核對工作區

## 使用流程

成績頁依所選學期整理待核對項目：空白成績、尚未確認含義的文字，以及需要核對的數值或格式。

- 「核對 N 筆成績」保留學期，清除搜尋、修別與成績類型篩選，避免隱藏其他待核對紀錄；畫面先說明這項行為。
- 原始分數、文字、學分與校方學期摘要不變，沒有資料庫或學分規劃寫入。
- 繼續搜尋、分批展開及 CSV 匯出都套用目前的待核對範圍；匯出不是只取畫面已展開的 40 筆。
- 更新後待核對數量變成零，仍保留返回全部明細的入口，不把使用者困在空清單。
- 未取得任何紀錄時不宣稱完整；來源失敗、校籍與帳號切換仍交由原有 AcademicPage / useAcademicRecords 處理。

## 判定界線

這不是新的及格判斷器。0、59、60、69.5、70 等合法數字均不因通過門檻而被列為資料缺漏。
SAT、等第、抵免與免修等未核實代碼保留原文，不推定通過，不調整後端推算或畢業採計。
大於 100 或負值只提示核對，不改成零分或擅自判定不及格。面板內學分合計是待核對紀錄所列學分，不是已取得或尚缺學分；無法確認的合計顯示未知。

另新增「模擬 HTTPS → 真實校務解析器 → 既有學分摘要 → 瀏覽器資料正規化」的回歸測試，分別檢查 Pass 的 0.5 學分與 SAT 保留但不加計、空白、零分、未通過、部分讀取和摘要故障。保留原有 academicSchoolSource.test.ts，不降低原測試門檻。
