## 6. CoursesHomeScreen fallback

當 TronClass cache、PU fallback 都沒料：自動載入 5 門 demo 課程，學生點進去每個 chip 都會看到完整資料。

```
loadAllData()
  → 1. getAnyCachedTCCourses / TCActivities / Attendance / Todos / Grades / PUFallback
  → 2. 若 courses 為空 + PU fallback 為空 → setTcCourses(demoFetchCourses())
  → 3. 背景再嘗試 TC 真資料；若有就覆蓋
```

## 7. Demo 演示流程（畢業專題簡報腳本）

1. **打開 APP，未登入狀態**：學習 → 我的課程 → 看到 5 門課（demo）。
2. **點「機器學習」課程卡** → 8 個 chip 全部可點：
   - 📚 教材：8 章節，每章內有 PDF / 影片 / web_link，附觀看進度。
   - ❓ 測驗：期中考 87 分、練習用小考 42 分、HW 補救 30 分滿分。
   - 📊 成績：作業 92、期中 87、期末微專題未交、出席 95 → 加權 88.5%。
   - ✅ 點名：12 週 rotating_qr 紀錄；第 4 週缺、第 8 週遲到。
   - 💬 討論：含「Clustering vs k-means」（老師置頂）、HW4 訓練不收斂等 3 串。
   - ✨ AI 學伴：AI 知道你還有 MQTT-NodeRED 沒交、期中考 87 分。
   - 📝 筆記：可寫 #期中 #SVM 標籤分類。
   - 💯 互評：HW3 K-means 2 份互評任務。
3. **回首頁 → 切「作業」分頁** → 看到本週要交：MQTT (5/29)、永續心得 (5/22)、矩陣作業 (5/18)。
4. **點 AI 助理** → 問「我這週要先做什麼？」AI 拿 demo course 資料給出排序建議。
5. **MyAttendanceHistory** → 跨所有課的出席率 + 異常警示。
