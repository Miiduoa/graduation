# 校方地圖來源

查核日期：2026-10-24。這些連結提供校方地圖與校區導覽，並不表示本站已接入該校地點資料、定位、無障礙路線或即時設施狀態。

正式公開目錄當日有 138 所學校；本次補足的是原有 21 所內建學校中的 13 個地圖入口。其餘學校仍需逐校核對，不以其他學校的地圖替代。

多校區學校由官方入口保留校區選擇。本站不從學校名稱猜測使用者所在校區，也不將圖面轉成未經核實的步行路線或公開廁所位置。
