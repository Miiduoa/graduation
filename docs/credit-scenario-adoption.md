# 比較方案直接採用與復原

在既有學分情境比較調整課程後，按「預覽並採用此方案」，核對改期與不再安排清單，再明確確認保存。同頁可復原這次採用；任何後續已保存編輯或帳號／校園切換都會使舊復原失效。重新整理或離開頁面不保留復原收據，長期備份仍用 JSON。

## 資料邊界

這不是選課、退選、畢業資格認定或雲端同步。只更新目前帳號與校園的本機規劃。比較只能變動未來課程的學期或是否排入；課程學分、狀態、已確認學分、目標、分類門檻與非學分條件不得暗中改變。

手機沿用同 scope 讀寫佇列與 session/revision。Web 在保存前比對 localStorage，並阻止本頁自動儲存覆蓋已觀察到的外部分頁更新。這是本機協調，不是對所有不合作分頁的資料庫原子交易。

有未完成課程輸入時 Web 阻擋採用／復原；手機檢查全部四區草稿並在讀取本機資料後再次檢查。既有 JSON 備份保留。沒有變更依賴、權限、正式資料庫或主線合併規則；本分支不包含未合併的 #321。

## 驗證

專項 contents:read 工作流程保留精確 head 的來源快照、純核心／Web／原生回歸報告與實際 Chrome 圖片。瀏覽器使用真實工作區及合成規劃，不登入學校、不發出外部資料請求。以實際報告與 SHA 為準；原生元件測試不等於實體手機驗收。
