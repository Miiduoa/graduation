# 學校公開資訊來源

本功能使用教育部統計處的[大專校院名錄](https://data.gov.tw/dataset/6091)，提供學校官網、名錄地址與總機。資料採[政府資料開放授權條款第 1 版](https://data.gov.tw/license)。

- 來源檔：[教育部 JSON](https://stats.moe.gov.tw/files/opendata/u1_new.json)。
- 下載日期：2026-10-24；來源最後修改時間：2026-08-03。
- 使用 115 學年度，原檔包含 103 至 115 學年度，不能把歷年資料混在一起對照。
- 原始 JSON SHA-256：`f004549a4e256143fad872ec5ec9e4992be01dc36cd9c9f32fe24b05bb1f1484`。

115 學年度共 139 筆。當日正式可選目錄的 138 所學校，名稱全部能與該年度唯一紀錄精確對應。聯絡資訊沿用正式目錄的學校代碼；中興的舊代碼 `tw-nchu` 僅在公開資訊查詢精確對應 `nchu`，不改校籍或權限。

世新 `shu` 已存在原始後端名錄種子，正式學校搜尋也可找到。完整目錄另有排除暫停校園的條件；本次未讀取其資料庫狀態，因此不推定排除原因，也不改寫管理設定或重複新增。

## 資料使用界線

地址是教育部名錄的機構地址，並非完整校區清單、使用者位置或經核對的設施座標。地圖連結以校名與地址進行文字查詢。總機不是校安、急救或特定處室電話。

電話中的範圍及分機保留原文，不把 `~` 或 `#` 移除後拼成新的撥號號碼。網站網址保留教育部原值；網站主機名稱不一定等同現行校名，不從校名猜測網站、信箱或登入網域，也不擅自把 HTTP 改寫成未核對的 HTTPS。

名錄不包含招生、校務登入、私人資料串接、營業時間或即時服務狀態。公開聯絡資訊不變更任何校園的開放設定。

## 更新方式

重新下載原始檔，記錄年度、下載日、來源修改時間與雜湊；只取最新年度，再按正式目錄的精確校名對照。名稱或代碼不符時保留未確認狀態，逐筆查核後更新，不用模糊比對將不同學校合併。
