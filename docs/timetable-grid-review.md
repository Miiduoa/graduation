# 截圖匯入的週課表核對

Web 與 Mobile 的個人匯入核對頁共用原本的待確認資料。點課程可編輯名稱、星期、開始／結束節次與教室；點空格補課。缺少星期或節次的資料仍會留在逐筆清單，不會被格子隱藏或自動略過。

具備完整節次時間表的跨節課可拆成單節後各自編輯，所有子課程繼承原列的匯入勾選狀態；同一天相鄰且名稱、教室、教師、學期及課班連結等資訊相同的課程可合併。節次變更會依已支援學校的節次表更新時間。未知學校保留數字節次與手動時間輸入，不猜測鐘點。沒有可用節次時間表時，拆分會顯示限制說明並保留原列，需手動新增與核對單節課程。

格子顯示待核對、需修正、已手動修改與重疊提示。正式資料仍在按下確認匯入並通過既有驗證後才寫入；刪除草稿課程、取消草稿均不刪除已存課表。辨識失敗也能直接點空格手動建立完整課表。

Web 沿用同一分頁的 sessionStorage 草稿；Mobile 使用按帳號及學校隔離的裝置草稿，序列化寫入並在重新進入時恢復。草稿包含欄位、選取狀態、核對問題及人工修改標記。Mobile 草稿讀取失敗會阻止覆蓋原草稿，寫入失敗會提示。

原圖沿用暫存畫面的隱私政策，不寫進正式課表或草稿儲存。重新進入後可使用「補上對照截圖（保留草稿）」重新選擇參考圖，不會重新辨識或覆蓋已修正的欄位。

驗證採兩端畫面行為測試，以固定辨識結果模擬錯讀與漏課，從可操作的課程格、欄位及確認後的紀錄斷言；另涵蓋辨識失敗的全手動路徑。測試不代表真實辨識引擎在所有截圖上的準確率，也未代替 iOS／Android 實機及瀏覽器視覺驗收。

Mobile 的格子編輯視窗使用安全區、鍵盤避讓與可捲動欄位，鍵盤開啟時可操作返回鈕。回歸測試涵蓋時間修改、返回後重開與確認儲存；實際安全區與鍵盤尺寸仍需在裝置驗收。
