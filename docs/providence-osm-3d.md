# 靜宜校園 3D：公開建築輪廓實作與驗收

## 目前入口

靜宜地圖 `/map?schoolId=pu` →「空間導覽」。開啟視窗後，Web 端才初始化 Three.js，並嘗試讀取同站 `/api/public/campus-footprints` 的輪廓快照。取得建築輪廓時，依經緯度換算成公尺後立體擠出；資料讀取失敗時仍提供原本的地點標記、列表與步行導航，不用任何假建築補滿畫面。

請勿把此版本描述為「靜宜數位孿生」、「真實 3D 建築」或「可室內導航」。目前是**以已知外輪廓繪出的建築量體示意**，不包含立面、屋頂、地勢、入口、高精度高度、樓板或無障礙通道。

## 來源與資料邊界

1. 校舍名稱、編號、用途及主顧樓樓層以[靜宜大學官方校園地圖實境導覽](https://www.pu.edu.tw/p/404-1000-1131.php?Lang=zh-tw)核對。官方另有[校史沙鹿校區地圖](https://archives.pu.edu.tw/p/412-1121-4218.php)，僅供核對，不重製照片、校方圖像及 720° 環景。
2. 建築座標及 OSM way ID 沿用專案共用 `packages/shared/src/providenceCampus.ts` 已記載來源的資料。此功能只請求其中 `cross-checked` 且來源為 OpenStreetMap way 的地點，不把公車站、停車場或單點建物硬擠成立體建築。
3. 伺服器向固定的 [OpenStreetMap Overpass](https://overpass-api.de/) 服務查詢指定 way ID，並檢查來源、閉合輪廓、座標是否在靜宜附近、合理面積、重複 way、形狀自交、非相鄰邊界相接與重疊。輪廓必須涵蓋對應的校舍 POI，或其邊界距離該 POI 不超過 30 公尺；避免 OSM way 遷移後仍冠上原校舍名稱。這是資料漂移容差，**不代表入口位置已驗證**。限制最多 128 筆來源圖徵、每棟最多 160 個頂點；避免把外站任意資料顯示成靜宜的校舍。
4. 即使 way ID 已在白名單內，也要確認 Overpass 回傳仍具有有效的 `building=*` 標籤；已移除建物標籤或標成 `building=no`、`construction`、`proposed`、`roof`、`ruins` 等不呈現完整建築量體。即使保留 `building=yes`，如同時帶有非否定的 `demolished:building`、`disused:building`、`abandoned:building`、`construction:building` 等生命週期標籤，也先拒絕渲染並待來源重新核對；這類互相矛盾的標籤不能當作建築仍存在或可進入的證據。無來源時保留地點標記而不補造建築。此判斷只表示 OSM 圖徵可用於外框示意，**不證明建物目前開放或可進入**。
5. 若 OSM `height` tag 是可解析的公尺數值，僅用於示意高度；缺少高度的建築以 12 公尺的**視覺示意值**繪製，絕不宣稱為量測結果。`building:levels` 不用公式直接猜高度。
6. 立體化來源需顯示 **© OpenStreetMap 貢獻者** 與[授權資訊](https://www.openstreetmap.org/copyright)。OSM 原始資料遵循 ODbL；如未來將修改後的建築資料對外散布，需再檢查相應署名與資料庫授權義務。正式產品應確認快照更新、API 使用政策與容量。

## 可靠性

- 服務端有 24 小時記憶體快照、同時請求共用、一般上游失敗後至少 10 分鐘冷卻；若 Overpass 回傳 HTTP 429／503 並提供有效 `Retry-After`（秒數或 HTTP 日期），尊重較長的伺服器等待要求（上限 24 小時），並回傳對應剩餘等待秒數供客戶端參考。不會在被限制時每 10 分鐘強制重試。避免使用者每次開 3D 都直接對 Overpass 發出大量請求。另有 500 KB 逐塊串流回應上限及識別 nuni 的 User-Agent，避免惡意／異常回應一次耗盡記憶體並符合公開 Overpass 的使用辨識要求。跨多台伺服器的冷卻不會共享；若流量成長，應改成受控的離線定期快照，而不是大量查公開 Overpass。
- 向 Overpass 請求 `out meta geom`，公開輪廓附 OSM way 版本與最後編輯時間（僅保留 `version`、`timestamp`，不回傳編輯者帳號等資訊）；在選取建築時顯示。**圖徵最後編輯時間不是資料抓取時間，更不是現場查證時間；OSM way 的節點可能移動而不改變 way 版本。** 舊快照或缺少合法 metadata 時不虛構版本；若 way 最後編輯時間比伺服器／裝置時鐘超前逾五分鐘，也只移除不可信的版本與日期，保留已通過獨立位置／建築標籤／外框驗證的輪廓，不宣稱該筆編輯時間已核實。
- 公開 Overpass 可能因負載限制回傳 429／503。現在會識別 `Retry-After` 的秒數或 HTTP 日期，遵守較長的冷卻並在舊快照仍有效時繼續標示舊資料。無快照時維持 503／`no-store`，不將 429 當成成功抓取建築輪廓。測試使用模擬回應，**不等於實際對公共 API 的容量或 SLA 驗證**。
- Overpass 回應若同時包含兩筆相同的**已核對建築 way ID**，即使其一的輪廓與標籤看似正確，也拒絕整份回應；同一圖徵不可能在一次查詢中同時具有兩種高度或外框。不能依回應順序默默取第一筆並宣稱來源可信。其他未列入建物白名單的圖徵不影響既有安全資料。已加入 parser 與 503／不快取 API 回歸。
- Overpass 的 JSON **即使 HTTP 200 也可能附帶 `remark`**（例如查詢逾時、記憶體不足），且 `elements` 可能只回傳部分結果。API 現在會拒絕所有帶頂層 `remark` 的回應，不把局部建物當成 24 小時完整成功快照；已有快照時依下述期限顯示過期備援，否則 503。此情況納入 API 回歸測試。參考 [Overpass 回應錯誤說明](https://overpass.ch/guides/overpass-api-errors)。
- 已有快照但更新失敗時會回傳來源時間與 `stale`，前端標明「暫用舊快照」。**七天未成功更新時不再提供舊建築輪廓**，改回傳 503 並保留原地點標記／平面地圖／外部步行導航，避免把長期失效資料看成現況。七天只是過期防護門檻，不等同現場核實期限。首次無快照且連線失敗時也只顯示原地點標記。
- 建築輪廓請求失敗時，靜宜 3D 視窗提供「重新讀取建築輪廓」，不用關閉空間導覽即可重試；重新讀取只發生在使用者點擊後，不自動無限輪詢。API 仍遵守 Overpass 的失敗冷卻與 Retry-After；按重試不保證服務已恢復，失敗時既有 POI、平面圖與導航仍可操作。
- Three.js 僅在開啟空間視窗時載入；對話框關閉、場景失去可見性或 WebGL 失敗時沿用原本的資源釋放、焦點、鍵盤、低動態與備援流程.前端建築輪廓請求最長等待 15 秒（含回應本體讀取），逾時中止請求、停止「正在讀取」提示並保留原有 POI、平面地圖與步行導航；此舉不代表 Overpass 線上可用性已驗證。元件回歸使用可被 AbortSignal 中止的模擬網路請求，驗證無限等待不會阻斷導航。
- 前端對回傳資料再次檢查學校 ID、建築 ID、來源網址、名稱、範圍及數值，阻止跨校或惡意輪廓混入。另要求 API 快照明示 `OpenStreetMap`、標準 ISO 抓取日期與布林 stale；若裝置時間判定已達七天、日期非法或超過五分鐘的未來時間，一律不顯示舊建築。即使快取錯報 `stale=false`，滿 24 小時仍顯示舊快照提示；裝置時鐘大幅失準時會保守回到 POI 與步行導航。尤其 `illustrative` 高度必須嚴格等於固定 12m，不能接受外部 API 中自行膨脹的 99m 示意樓高；若回應不一致，該建築不會顯示，保留原有 POI 導覽。

## 需驗收，不可直接說已超越競品

- [ ] 真實線上 Overpass 回傳：確認已核對的靜宜建築輪廓數量，逐棟對照 OSM 原始 way 與校方位置，保留失敗樣本。
- [ ] 建築外觀：若要宣稱「像真」，需逐棟取得合法的建築立面參考、自製貼圖和模型，人工目視校正；目前僅外輪廓。
- [ ] 樓層／室內動線：與已合併的 #533、待審的 #543 的圖面格式接續，但不得把未校正的手動圖面當成公開室內導航。
- [ ] 裝置測試：iOS Safari、Android Chrome，320／390／1280px、200% 字級、弱網路、WebGL context loss、鍵盤與螢幕閱讀器。
- [ ] 同校同任務與 Google 地圖、Apple 地圖、校方環景、UniTable 做可重複的操作比較，記錄成功率、錯誤目的地、步數、中位耗時、裝置效能與證據。詳見 [campus-spatial-benchmark.md](./campus-spatial-benchmark.md)。
- [ ] 以上完成且靜宜實際有明確優勢後，再逐校新增**各校自己的**地圖邊界、POI 校核與建築輪廓，不以靜宜資料冒充他校。其他學校的選校／一般地圖功能不受此功能阻擋。

## 測試

```sh
pnpm --filter web exec vitest run src/app/map/providenceFootprints.test.ts src/app/map/CampusSpatialExplorer.test.tsx src/app/map/campusSpatialScene.test.ts src/app/api/public/campus-footprints/route.test.ts
pnpm --filter web exec tsc --noEmit
pnpm --filter web build
```

不需新的付費套件或 API key；但公開 OSM 資料服務仍有可用性與合理使用限制。
