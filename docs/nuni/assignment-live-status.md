# 作業狀態同步

nuni 自有課程使用 class-workspaces 授權 HTTP 端點，與群組點名的 Firestore 文件不同。此次重用前景啟停的生命週期，對目前課程的作業清單採完成讀取後間隔 2.5 秒補讀；沒有新增資料表、事件來源、常駐服務或權限。每個清單同步流程同時最多一筆請求，教師最後選取且可見的一份作業收件使用獨立排程，不逐人查詢學生。主清單更新不會重開或作廢在途收件讀取；兩份清單都在讀取完成後才等待 2.5 秒。

「已同步」代表最近一次伺服器清單讀取成功，「最後更新」是該次讀取完成的裝置時間。讀取中、離線或失敗都不冒充最新狀態。送出作業仍沿用既有伺服器確認收據；上傳完成不代表繳交成功。

頁面隱藏、pagehide 或 App 進背景會停止後續更新並作廢舊回應，回前景立即補讀。已送出的 HTTP 請求不會撤銷伺服器執行，但其晚到回應不會更新主清單或收件。回饋儲存成功會增加 mutation revision，先前開始的自動收件讀取因此失效，再補讀新資料。登出卸載課程畫面；401、403、404 或工作階段變更會清空清單、停止排程並移除事件訂閱。新取得的伺服器清單可取代作業卡暫存收據，包含其他裝置撤回的結果，編輯中的草稿保留。

## 自動檢查

只使用合成資料，設定 EXPO_NO_DOTENV=1，不讀取環境檔或金鑰、不連正式資料庫。

- Web：assignmentLive、AssignmentCard、CourseAssignments、NuniApp 測試。
- Mobile：assignmentLive、NuniCourses 測試，快取僅使用 /tmp/jest_rs。
- 整個專案執行 pnpm typecheck 與 pnpm lint。
- 同步測試包含兩個獨立客戶端讀取同一份合成狀態、2.5 秒內接收退回狀態、離線保留時間、背景停止、回前景補讀、撤權停止、晚到回應失效。

## 測試環境待驗收

自動測試的兩個合成客戶端不等同兩個實際登入裝置。部署至隔離測試環境後，應以測試帳號在 Web 與 Mobile 分別完成：

1. 學生送出後，另一端在五秒內看到伺服器收據；教師新增或修改回饋後，學生端在五秒內看到更新。
2. 學生撤回後，另一端清除原收據；未送出的文字草稿保留。
3. 斷網顯示離線及最後更新時間；恢復連線後補讀。
4. 隱藏頁面／App 背景期間不再發出定期讀取，回前景立即讀取。
5. 登出與撤權後，清單和收件內容不可再見，網路記錄不再出現同步請求。

實際延遲包含端點回應時間，不能保證所有網路條件都在五秒內。清單仍受既有最多 100 份作業範圍限制。前景補讀每分鐘約 24 次，最多另加一份選取收件清單，部署前需觀察既有服務額度；沒有免費無限規模承諾。校方 LMS 等未串接來源標示不支援即時。

## 可見範圍、退避與負載門檻

- 只有目前課程的作業分頁自動讀取主清單。切換教材、測驗或其他分頁即停止；隱藏頁面與背景也停止。
- 每門課最多一份教師收件清單自動更新，以最後點選「查看收件／更新繳交內容」的作業為準；切換選取、搜尋隱藏卡片或 Mobile 收合卡片都停止該份自動更新，草稿仍保留。其他已開啟的收件保留最後讀取內容與時間。
- 收件有自己的同步狀態與最後更新時間。非權限錯誤採 5、10、20、40、60 秒退避，之後維持 60 秒；成功後回到 2.5 秒。權限拒絕及工作階段變更清空並停止。
- 手動更新與自動讀取依序執行，避免同一份收件重疊。前景世代在背景事件當下失效，不能因回到前景就重新採用背景前快照。

合成假時鐘測試的邊界：連續前景一分鐘、零延遲成功端點，主清單含首次讀取共 25 次，選取收件首次手動讀取後的自動更新 24 次。穩態兩者合計每分鐘最多約 48 次；隱藏／非作業分頁的定期讀取為零。在途收件延遲 10 秒且主清單持續更新時，不新增重疊收件請求，完成後仍接受結果。這些是用戶端排程量測，不能推估 SQL 次數或資料庫實際費用。

隔離環境發布前門檻：以 100 份作業、每份 100 份合成收件，測量 10 個前景客戶端連續 10 分鐘的端點 p95、回傳位元組、API／資料庫查詢數、CU-hours 與每層 egress。每客戶端僅一份自動收件；穩態每分鐘至多 48 次，單份收件在途至多一筆；非作業／背景停止後無新定期請求。若要宣稱五秒可見，包含 2.5 秒間隔的全鏈路 p95 必須不超過五秒；慢端點測試只證明不重疊、不飢餓，不代表達成五秒。每月推估增量必須低於各服務實際剩餘免費額度的 50%，並納入既有負載；無法取得剩餘額度或任一門檻未過，就不宣稱免費方案可供整班長時間使用。本次未部署，也未連線量測上述全鏈路門檻。
