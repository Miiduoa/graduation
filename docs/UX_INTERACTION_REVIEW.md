# Web 互動維護

更新日期：2026-10-12。對應 PR #31，範圍為個人課表、校園選擇器與共用確認視窗。

## 課表

空白格直接新增課程，點選已有課程開啟編輯。重疊課程全部保留並標示，連堂格顯示續堂；未排定或時間不完整的課程集中在「待排時間」，不會因切換顯示方式而消失。

電腦可拖移整門課。從續堂格抓取時保留抓取偏移，目的地放不下完整節次就拒絕，不自動縮短課程。手機與鍵盤使用「移動課程」選單，再選擇新起始節次。拖放與點選都只建立編輯草稿，顯示原時間與新時間，確認儲存後才更新；移動後取消仍須經過未儲存確認。

無法確認儲存結果時，保留編輯內容與匯入草稿。若持久層明確回報 `TimetableCloudSaveError`，代表本機已寫入，畫面顯示本機版本並說明雲端未同步，不把已存好的內容說成沒有儲存。送出期間鎖定相關欄位，避免重複寫入；匯入至少需要勾選一門課。讀取失敗時提供重試入口。成功儲存後清除先前規劃結果與畫面上的分享連結；這不會撤銷已發出的連結。

空白或含未排定課程的個人課表，不提供空堂、讀書時段或邀約建議。好友課表缺少資料、校園不符或含未排定課程時，同樣不推算共同空堂。資料檢查只能檢查已知課程，不能保證未匯入課程與臨時調課不存在。

介面工作區依帳號與校園區分。切換時清除上一個工作區的私有內容，舊請求回傳後不更新新工作區。修改文字或選擇新的匯入來源後，忽略先前的截圖辨識結果。這是介面與請求生命週期隔離；既有持久層仍使用單一 current 課表，完整多校儲存遷移不在本 PR 範圍。

分享連結建立與剪貼簿寫入分開處理。複製失敗時顯示可選取的連結；只有剪貼簿寫入成功才顯示「已複製」。保留主線的學校帳號說明及登入入口，本機課表不等於已同步到帳號。

一週清單依五個上課日排版，平板兩欄、窄螢幕單欄。相關按鈕靠近排列，不把同一項操作的控制項分散到面板兩端。編輯欄位使用 16px 文字與至少 44px 操作區。

## 確認視窗

使用原生 `dialog.showModal()`，並管理焦點返回與巢狀視窗的捲動鎖。確認視窗初始聚焦取消按鈕；等待 `onConfirm` 回傳的 Promise 或外部 `loading` 時，不接受重複送出或關閉操作。呼叫端須回傳操作的 Promise，或維持正確的 `loading` 狀態。

內容區獨立捲動，標題與操作列保留在視窗內。窄螢幕使用堆疊按鈕，關閉按鈕為 44px，並處理動態視窗高度、安全區及減少動態效果偏好。

## 校園選擇器

搜尋支援台／臺、全形英數、大小寫與多關鍵字。搜尋只篩選目錄，不改變目前校園；保留的原選擇須另行標示，不計入符合數量。清除搜尋後返回輸入框，選定校園或焦點離開時收起選單；中文組字中的 Esc 不關閉選單。

`Timetable Browser` 工作流程建置 standalone Web，在 CI 本機訪客環境執行 Chromium，不向正式服務寫入。涵蓋超出節次拒絕、鍵盤移動與取消、原生拖曳後儲存重載、390px 非拖曳操作及未排定課程的規劃限制。截圖、拖曳事件、trace 與失敗診斷保留在 workflow artifact。拖曳以實際滑鼠輸入執行，並要求瀏覽器原生的 trusted drop 事件，不用手動派發 DOM 事件代替。
