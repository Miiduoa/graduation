# 校園地圖第一版（靜宜）

## 結論與範圍

第一版只做靜宜大學，與公車第一版同校。學生從「生活 → 校園地圖」進入
（底欄仍是 今天｜課務｜生活｜我，不新增底欄項目），在同一張地圖上看：

- 校園範圍內的主要建築與設施（教學大樓、圖書館、餐廳、宿舍、運動、停車等）
- 公車站牌位置；點站牌後按「查看即時到站」到公車頁看即時到站
- 一筆 OpenStreetMap 閘門標記的出入口，正式名稱待補

其他學校不套用靜宜資料：Firestore 沒有地點時維持「目前沒有可顯示的
校園地點」，各地點標待補。

## 查到的現況（沒有從零重做）

- 網頁已有 `/map`（Leaflet + OpenStreetMap 底圖）、搜尋、分類、收藏、
  步行導航外連與手機版式；手機 App 也有 WebView 地圖。本版只補資料與
  站牌連結，不重做這些功能。
- 網頁地圖原本只讀 Firestore `schools/{schoolId}/pois`；查不到地點時
  只剩校方平面圖連結，沒有可點的建築。
- repo 內舊的靜宜建築清單（`apps/web/src/lib/campusPoiLookup.ts`、
  `apps/mobile/src/data/puCampusData.ts`）座標約在東經 120.564 一帶，
  與校方公布的 GPS（北緯 24.2257、東經 120.5772）、OpenStreetMap
  校園範圍（東經 120.5769～120.5844）及臺中站牌座標對不上，差約
  1.6 公里。本版不沿用那批座標，已另列黃燈，手機端舊清單未在本版處理。

## 使用規則

- Firestore 有地點時以它為準，只補還沒有的公車站牌。
- Firestore 確認為空時，靜宜才改用隨附的 OpenStreetMap 建築資料。
- Firestore 讀取失敗時顯示錯誤與重試，不拿隨附資料假裝同步成功。
- 站牌的路線只列名稱；到站分鐘一律到公車頁查即時資料，地圖不自行推估。
- 不需要新金鑰、不花錢；沒有申請任何新帳號。

## 怎麼驗

```sh
pnpm --filter web exec vitest run src/app/map/providenceCampus.test.ts src/app/map/MapClient.test.tsx src/app/map/MapCanvas.test.tsx src/app/map/mapService.test.ts src/app/map/page.test.tsx
pnpm --filter web exec tsc --noEmit
pnpm --filter web build
```

人工驗收（部署後）：開 `/map?schoolId=pu`，確認看得到主顧樓、蓋夏
圖書館與靜宜大學（校門）站牌；點站牌後「查看即時到站」到
`/bus?schoolId=pu`；手機寬度下地圖與地點列表可操作。

## 待補與黃燈

- 出入口：目前只有一筆 OpenStreetMap 閘門標記且名稱待補；正門、後門
  的正式位置待校方資料或實地核對後再補，不自行猜測。
- 舊靜宜建築清單座標偏差（約 1.6 公里）：`campusPoiLookup.ts` 與手機
  `puCampusData.ts` 仍被其他功能引用，本版未更動，需另開一線逐筆
  用 OpenStreetMap／校方資料核對後修正。
- Firestore 正式地點若之後補上，會自動成為主資料；隨附資料的更新
  方式比照公車靜態快照：重新查詢、記錄日期與來源後才替換。
- 其他學校：維持待補，有該校可回查的真實座標來源後再逐校加入。

## 逐筆核對結果（2026-10-19，第二輪）

核對方法：建築逐筆把點位放回 OpenStreetMap 對應建築的範圍裡檢查
（落在棟內才算位置對），名稱再與校方「校園地圖實境導覽」名單
（https://www.pu.edu.tw/p/404-1000-1131.php?Lang=zh-tw ）對照；
站牌逐筆與臺中靜態資料的 TCOD 代碼及 OpenStreetMap 站牌節點比對距離。

### 對得上（19 筆建築＋10 筆站牌）

- 建築 19 筆：主顧樓、任垣樓、伯鐸樓、文興樓、格倫樓、方濟樓、思源樓、
  靜安樓、至善樓、蓋夏圖書館、主顧聖母堂、修院、靜園餐廳、宜園餐廳、
  思高學苑、若望保祿二世體育館、溫水游泳池、保健中心、靜宜大學郵局。
  全部點位都落在各自建築範圍內；保健中心與郵局的點位落在至善樓範圍內，
  與校方名單「至善樓：保健中心、郵局」一致。主顧樓另與 Google Maps
  地點座標（24.227105, 120.583577）比對，相距約 18 公尺、同一棟。
- 站牌 10 筆：座標與路線（含往哪個方向的目的地）都保留 TCOD 代碼
  （寫在 `providenceCampus.ts` 的 `transitStopIds`），與 OpenStreetMap
  站牌節點逐筆距離多在 15 公尺內。其中「靜宜大學（校門）」兩來源差
  約 26 公尺、「靜宜大學主顧聖母堂」差約 39 公尺，是同一站牌區的
  不同落點（道路兩側／沿路位置），地圖採用公車資料那份座標為準，
  因為即時到站也是跟公車資料對的；這兩筆在實地驗收時要再確認一次。

### 有出入、已修（3 筆）

- 「宜園」→ 校方正式名稱是「宜園餐廳」，已改名。
- 「游泳池」→ 校方正式名稱是「溫水游泳池」，已改名。
- 「郵局 ATM」：只有 OpenStreetMap 單一節點，又不在任何已核對建築
  範圍內，無法交叉確認，已先拿下（第一版 24 筆建築變 23 筆）。

### 只有單一來源、先保留但標待確認（4 筆）

- P1 停車場、P2 停車場、機車停車場：點位落在 OpenStreetMap 標記的
  停車範圍內，但名稱只有這個來源，校方名單沒有逐一對照到。
- 校園出入口（名稱待補）：OpenStreetMap 閘門標記，位置與校方公布的
  GPS 導航點（24.2257, 120.5772）只差約 11 公尺，但正式名稱未確認。
- 這 4 筆在地圖清單會顯示「待確認」，詳情會明講只有單一來源；
  拿到校方或實地第二來源後再升級為已核對。

### 還沒放上地圖的校方地點（待補）

校方名單有、但 OpenStreetMap 沒有可確認座標的：希嘉學苑、綜合運動場、
綜合球場。先標待補，不自行猜位置放上去。

### 舊清單的影響範圍（這一輪沒有全面翻）

`apps/web/src/lib/campusPoiLookup.ts` 與手機
`apps/mobile/src/data/puCampusData.ts` 的舊座標偏約 1.6 公里，仍被
課程地點比對、手機地圖與 AI 導航等功能引用。這一輪只確認它不影響
本版網頁地圖（本版用的是重新核對過的資料），舊清單逐筆翻修要另開
一線處理，影響範圍先記在這裡，不假裝已修好。

## 競品差距與這一輪落地的體驗（2026-10-19）

實際查核的對照組與依據：

- Google Maps（官方說明 https://support.google.com/maps/answer/144339 ）：
  步行路線、站點即將到站車次做得完整；但校內建築要先被 Google 收錄
  才搜得到（臺大計資中心也說明系館未標在 Google 地圖上時無法導航，
  https://www.cc.ntu.edu.tw/chinese/spotlight/2017/a105033.asp ），
  它也不會告訴你這個點的資料有多可信、更不會接你的課表。
- Apple Maps：校園建築覆蓋同樣依收錄狀況，沒有校內分類與站牌即時
  到站整合；本輪未逐筆實測，列為下一版實機對照項目，不憑印象下結論。
- 學校官方校區地圖（靜宜校區平面圖與實境導覽）：名稱最權威，但只有
  平面圖與名單，不能搜尋、不能看距離、不能連公車即時到站。
- Bus+（商店頁 https://play.google.com/store/apps/details?id=hearsilent.busplus ）：
  站牌地圖、進／出站方向、收藏與提醒做得好；但它不知道你在哪間學校、
  哪一棟建築，也沒有校內地點。
- 台灣等公車（商店頁 https://play.google.com/store/apps/details?id=nexti.android.bustaiwan ）：
  附近站牌與常用站牌群組完整；缺點同樣是沒有校園建築這一層。

nuni 要贏的點與目前狀態：

| 要贏的點 | 狀態 |
| --- | --- |

| 校內建築搜尋與分類，且每個點都附來源、可信程度老實標 | 這一輪落地：搜尋可打路線編號找站牌；單一來源顯示「待確認」 |
