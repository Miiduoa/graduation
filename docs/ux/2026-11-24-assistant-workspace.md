# nuni 首頁、探索與全站工作空間改版

日期：2026-11-24（Asia/Taipei）

## 目標與版本基礎

把日常任務放在使用者進站後最容易開始的位置，並讓 Web 與 App 使用同一組主要目的地。首頁負責開始或接續眼前的事，探索頁負責示範實際可用的任務，既有課務、交流、生活與工作服務仍可直接進入。

此版本從 PR #785 的 `6eb2c4c7b7bd657f5a40cc65ad6a79f8bd886eaf` 建立獨立分支 `feat/nuni-assistant-first-workspace-20261124`，沿用 #781、#779、#768 的現有設計與整合血緣。先整合 main `7232919a8cc68ce01a2eaba9704268ddf3924bc0`，合併時保留地圖名稱／目錄／別名的解析優先序，以及 `tw-pu` 公開校園範圍。最後再同步 main `7953ae4400295998a7d69dd2e017d53ef97e6160`；最後一次合併僅更新 lockfile 的兩筆 acorn 解析，Web、Mobile 與 shared 程式碼未變。這些既有分支的內容不計為本輪新增功能。

產品方向參考 [ChatGPT 新版行動介面的 Home／Explore 分工](https://help.openai.com/en/articles/20001723-using-the-new-experience-in-the-chatgpt-mobile-app)。實作保留 nuni 的校園、課務與多角色需求；這份改版不代表 OpenAI 官方團隊參與。

## 整體資訊架構

| 目的地 | 主要工作 | 相容性 |
| --- | --- | --- |
| 今天 | 問題輸入、當日課表、待辦與各角色工作入口 | 原有學生、教師、店家與管理工作內容保留 |
| 探索 | 18 個任務起點、情境與分類篩選、相關服務接續 | Web 新增 `/explore`；App 保留原 `校園` tab ID |

Web 寬螢幕使用固定側欄；手機寬度保留五項底部導覽及安全區。舊 `/life`、原生 `CampusHome` 與 `campus` 深連結均保留，探索頁及側欄提供服務目錄入口。

## 首頁與任務接續

首頁以「今天想完成什麼？」作為任務入口，提供符合目前情境的三個範例。點選範例只填入並聚焦問題；按「繼續」接到現有助理，仍由使用者決定送出。當日課表、教師待辦與店家待接單內容仍可直接操作。

Web 的對話區限制高度，避免長對話把當日工作推離首頁。Native 共用 `WorkspaceStart`，店家版採可展開的精簡入口。不同入口沿用既有 assistant contract，不新增自動執行或隱性寫入。

工作情境包含學生與個人、教師、店家、社團幹部、校務與課務、平台管理。情境只決定展示及預填，不能更換帳號、取得角色或擴張資料存取。首頁以已確認角色選預設範例，不猜測店家或社團資格。

## 探索內容與能力一致性

`packages/shared/src/assistantExperiences.ts` 集中定義 18 個任務、分類、搜尋詞、問題與實際服務 ID。分類為安排一天、處理課業、探索校園、參與交流、進入工作。所有任務 ID 唯一，服務 ID 對應既有服務目錄。

Web 的搜尋與分類／情境篩選保存在網址，可返回原搜尋；相關服務連結保留校園範圍。卡片同時提供預填問題及直接開啟服務的操作，並顯示服務所需帳號或資格。

Web、Legacy 校務助理與 Native 的能力並不完全相同，因此原生透過 `mobileWorkspaceExperience` 投影為確實能解析的語句。例如下一堂課、待交作業、七天規劃、館藏入口與開啟服務，都使用現有 parser 支援的形式。原生教師／店家概況接到正式工作服務，不宣稱已具備尚未實作的概況 reader。

Legacy 助理的教師／店家情境使用既有 role task guide 接續服務，不把工作查詢交給一般校務助理冒充工作 reader；非學生情境不自動載入學生個人修課摘要。

## 失敗與草稿恢復

校園目錄錯誤、尚未選校、訪客及登入確認失敗，都保留並顯示原問題。目錄重試沿用現有 provider；選校沿用現有 SchoolSelector。畫面提供返回探索、相關工作區及公開校園服務，避免只留下錯誤文字。

沒有雲端助理設定時明確顯示目前狀態，各服務依自身連線及權限呈現。選校與登入返回網址保留 `q`、`taskProfile` 及校園資訊，不自動送出。帳號或校園切換會使舊草稿失效；使用者明確建立的新交接須綁定新的作用域。

## 全站視覺與可及性

Web 與 App 改用系統無襯線字體、白色／中性灰表面與較明確的標題層級，保留 nuni 深綠品牌與深色／OLED 模式。標準正文 16px、次要文字 14px；Web 小／中／大字偏好的正文為 15／16／18px，首次繪製與 hydration 共用同一份字級表。

桌面側欄在高度不超過 600px 時收起次級工具，讓主要導覽保有可捲動空間。桌面固定布局限定螢幕，避免影響列印。鍵盤焦點框、減少動態效果、既有安全區及設定選項保留。原生啟動畫面、adaptive icon 背景與 iOS widget 亮色背景同步更新。

- 瀏覽器縮放得到 681px 與 340px 內容寬度，沒有橫向內容溢出，五項底部導覽皆可見。這是 Web 窄版檢查，不是原生手機驗收。

## 發布界線

本輪不代表所有後端功能、真人登入或所有角色的正式資料讀寫已驗收。尚未執行 iOS／Android 模擬器或真機建置，也沒有用真實帳號建立訂單、送交作業或修改校方資料。Maestro 導覽腳本已同步，但不能以腳本更新當作執行成功。

正式合併及部署仍須依精確候選版本核對完整 CI，以及現有 ruleset 26004626 指定的 `nuni-merge-gate` App 5504170「審查通過」。本文件與本機測試不替代該核可，也不代表正式站已更新。

## 後續產品驗收

優先驗證三條完整旅程：學生從首頁處理下一堂課與待交作業；教師從工作入口處理授課／備課；店家從工作入口處理當班工作。以成功完成率、入口至完成所需步驟、錯誤後恢復率及各裝置可讀性判定改版效果。未經真實資料與裝置驗證，不宣稱效能提升幅度或勝過其他產品。
