# 成績學期歸屬與讀取範圍

## 使用者流程

學號登入後讀取成績 → 查看本次來源提及哪些學期 → 展開「學期資料範圍」 → 點選學期核對完整明細 → 必要時更新或回 e 校園核對。

- 範圍只來自成績列、來源學期清單和校方學期摘要，不以入學年或學期間隔猜測修業紀錄。
- 來源有學期卻沒有科目明細時，明示「尚無明細」，不宣稱沒修課或取得零學分。
- 查看學期會保留該學期、清除可能遮住紀錄的搜尋／修別／成績類型／待核對篩選，並重設為40筆展開。
- 顯示校方摘要不代表已取得該學期明細；原始平均、排名與分數仍保留。
- 匯出沿用既有使用者點擊流程，僅匯出目前符合條件的紀錄；學期清單本身不觸發下載或額外校方請求。

## 解析修正

- 同張表中的獨立學期標題可切換學期。正常科目列中的學期文字不會改變其他列歸屬。
- 未能辨識的獨立學期標題或 caption 會清除舊學期上下文；不把後續科目靜默歸到上一學期。
- 重複表頭會重新建立欄位對應，容許欄位順序改變。
- rowspan 不跨 thead／tbody／tfoot，rowspan=0 僅延伸至同列群組末端，仍保留展開上限。
- 「課號／科目編號／課程編號」保留來源值與前導零；不猜造課號。
- 無法表示為有限數值的學分列標記部分讀取；溢位成績保留文字待核對，不輸出 Infinity 使整份資料無法處理。

## 驗證與邊界

新增26項解析器回歸、10項範圍核心測試與8項實際頁面互動測試。既有完整 CI、來源整合測試、瀏覽器版面及實際 CSV 下載檢查保留；檢查結果應以確切提交的 Actions 紀錄為準，不能拿前一提交的結果當作本次通過。

範例均為合成資料，尚不證明真實校方帳號的資料完整性。不修改校方資料、帳密、Cookie、來源網址白名單、正式資料庫、登入開關、依賴或畢業採計規則；沒有新增背景抓取。此修正不代表完整 TronClass 同步、正式畢業審核或 iOS 實機驗收已完成。
