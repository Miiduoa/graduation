# nuni 畫面盤點

盤點範圍：`apps/web`（Next.js App Router）與 `apps/mobile`（Expo／React Navigation）。登入、驗證、session、權限、路由守衛、API route、環境變數、Firestore 規則、資料庫與 migration **不在本次處理範圍**。登入頁內容另有分支處理，本文件只列出路徑、不建議改動。

判定：

| 判定 | 意義 |
| --- | --- |
| **A 刪除** | 沒有站內入口或僅剩死碼；或新版已提供同樣功能且舊檔不再被導覽使用。本 PR 刪除。舊網址若可能被書籤則保留 redirect。 |
| **B 待決** | 使用者仍點得到，且是目前唯一提供該功能的畫面。刪了會少功能，本 PR 不刪。 |
| **保留** | 現行產品畫面，有入口且仍在使用。 |
| **redirect 保留** | 舊網址已改成導向新頁，本 PR 維持 redirect、不刪網址。 |

## App：導覽與畫面

底部入口：今天（HomeStack）、課務（LearnStack）、校園（MapStack）、我的（MeStack）；訊息（MessagesStack）從「我的」進入。未登入走 PreAuthStack。

### 已註冊且仍提供功能（摘要，判定＝保留）

今天：`TodayHome`（`RoleAwareTodayScreen`／學生或教師今天頁）、公告／活動、社群、校園助理、行事曆、校園漫步。  
課務：`LearnHome`（角色感知 landing）、課表／匯入、課程中樞與教材作業測驗討論、成績、申訴、店家工作台、點名等。  
校園：地圖、公車、餐廳、圖書館、失物招領、支付等。  
訊息：`Inbox`／`MessagesHome`（`MessagesLandingScreen`）、群組、私訊。  
我的：個人、設定、通知、學伴、除錯／預覽、管理守衛頁。

別名路由（同一畫面、舊名仍註冊以便深鏈）：`CoursesHome`／`TeachingHub` → 課務 landing；`Map`／`MapV2`；`BusSchedule`／`BusV2`；`AIChat`／`AIAgentConsole`／`AIAgentObservatory` → 校園助理。**不刪路由名**（避免深鏈失效）。
