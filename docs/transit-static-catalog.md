# 臺中官方靜態公車站牌快照

本模組供 `/api/transit` 在伺服器端查詢校園站牌、站名及附近站牌。資料包含站名、位置、路線、去返程與目的地；**不包含車輛位置、班次或預估到站時間**。`catalogDate` 是檔案下載完成時間，不代表官方資料最後更新時間，更不能當作公車動態時間。

## 來源與授權

- 提供機關：臺中市政府交通局。
- 資料集：[臺中市市區公車站牌資料](https://data.gov.tw/dataset/81555)。官方頁面標示免費、不定期更新。
- 原始 CSV：[官方下載](https://newdatacenter.taichung.gov.tw/api/v1/no-auth/resource.download?rid=da150269-0aed-48fc-954c-087e100090ec)。不需要帳號、API 金鑰或 TDX 憑證。
- 授權：[政府資料開放授權條款第 1 版](https://data.gov.tw/license)。產品顯示來源時應保留機關及資料集連結。
- 快照：`apps/web/src/data/taichung-transit-catalog.json`，只能由伺服器端模組引用，避免將整份約 4 MB 的名錄放進瀏覽器 bundle。

原檔開頭有重複 BOM。最後一筆「市民小巴4延／去／太平里」的地址欄缺少結尾雙引號；兩次下載內容的 SHA-256 相同。轉換器排除這一筆不完整紀錄，沒有補造引號或欄位。只有末列最後一個地址欄缺結尾引號且未跨行時允許排除，其他 CSV 結構錯誤會停止更新。此行的站牌仍有其他完整路線紀錄，所以排除後站牌項目數沒有減少。以上計數也保存在快照 metadata，refresh 指令會輸出。

部分原始「站點編號」與「地址」為空，這兩欄不是顯示資料，也不補造。所有採用列的站名、路線名、去返程、目的地與經緯度都有有效值。座標保留原始數值精度，允許臺中市區公車延伸至鄰近縣市的路線；回傳 `city: 'Taichung'` 表示所屬資料源，不是行政區地理判定。

## 身分、去重與查詢

站牌 ID 為 `TCOD_` 加上真實欄位 SHA-256 的前 40 個字元，輸入由原站點編號、站名、完整數值座標與去返程組成。這個 ID 僅屬於本靜態資料集，不能傳給 TDX 到站查詢，也不能依名稱猜測對應的 TDX StopUID。

相同名稱但不同座標或去返程會保留不同 ID；完全相同的路線名稱、方向和目的地才合併。各路線的「去／返」是路線相對方向，沒有推測東西南北方位。快照 ID 與輸出排序不依賴原 CSV 列順序。

`searchTaichungCatalog()` 接受 campus/search/nearby 查詢，回傳 `{ stops, limited }`。campus 目前只支援 `pu` 的「靜宜大學」站名；其他校園不混用資料。站名支援子字串、全半形及台／臺正規化。定位使用實際座標算距離並排序，所有查詢最多回傳 16 筆，超出才設 `limited: true`。API 層仍須保留自身的參數驗證與速率限制。

## 更新與驗證

```sh
node scripts/refresh-transit-catalog.mjs
node --test scripts/refresh-transit-catalog.test.mjs
pnpm --filter web exec vitest run src/lib/transit-catalog.test.ts
```

更新指令只向固定官方 URL 下載，拒絕重新導向、HTML/XML/JSON 錯誤文件、非 UTF-8、欄位變更、錯誤座標及過小資料集。下載與驗證完成後才原子替換 JSON；來源失敗不會覆蓋現有快照。更新後應檢查 metadata 中的來源 hash、排除列數、站牌數量與來源日期，再走正常測試及部署。快照不會在請求期間或排程中自動下載；重新執行更新指令也不會自動發布。

## 執行與發布狀態

`/api/transit` 只在兩個 TDX 環境變數均未設定時，為臺中校園、搜尋及附近站牌使用名錄；其他縣市仍明確回報未設定。只設定一個變數或空字串不會悄悄切換。已設定完整 TDX 時維持既有提供者流程。`TCOD_` 到站查詢一律回報 `not-configured`，不會把本地 ID 傳給 TDX。

Web/App 解析同一份來源欄位；靜態站不輪詢即時到站，提供路線、官方查詢與步行導航。已發布的 Android code 7 只能使用原有基本站牌介面，本輪新 App 介面需下一版建置及 Play 發布才會生效。

Web release 使用新增 `static-catalog` profile。此 profile 仍要求相同主線 SHA 的完整 CI、既有機器與來源鎖定、執行環境無 TDX 金鑰；發布後驗證靜宜校園／站名／附近查詢、來源日期與 ID、官方提示、即時到站未設定及跨縣市狀態。成功僅代表靜態名錄可用，不宣稱即時到站或實機定位已驗證。
