# 共用導覽、等待與通知體驗

## 使用者遇到的問題

- 原生抽屜用固定 220ms 計時器換頁，連點不同入口可能排入多次導航；旋轉後仍沿用啟動時的寬度。
- 原生通知在 App 背景仍倒數，訊息只顯示兩行；大字、長訊息與輔助閱讀時容易遺失結果。
- 原生按鈕送出時把原操作名稱換成「處理中」，原圖示也被替換，造成寬度與閱讀位置變動。
- App 有減少動態設定，但抽屜、通知與共用卡片沒有一致套用。
- Web 課程列表用 Escape 取消注音選字時，可能清除搜尋及課表來源；清除按鈕消失後鍵盤焦點掉回頁面。
- 地圖、登入確認、課程與助理的載入提示使用不同呈現方式。

## 設計決策

延續 nuni 的色彩、字型與校園品牌。參考 Apple 的 [Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility) 與 [Layout](https://developer.apple.com/design/human-interface-guidelines/layout) 原則，動畫表達狀態改變，操作與內容在偏好變更後仍保持可用。

| 共用位置            | 行為                                                                                                                                                                               |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HeaderDrawer        | 第一個選擇開始關閉，動畫確實完成後才導航一次；重開、取消、卸載及身分變更使舊動作失效。即時視窗寬度與完整換行支援旋轉、大字及分割畫面。                                             |
| useReducedMotion    | 系統與兩個既有 App 設定任一要求減少動態即生效。共用一個原生觀察者；初次未知時保守呈現，已知偏好供後掛載元件同步使用。即時事件優先於較早的非同步查詢。                              |
| 原生 Button         | 保留原名稱、圖示與可讀對比，使用不佔排版空間的細進度線；提供 busy 語意、阻止處理中再次按下，支援完整換行。                                                                         |
| 原生 AnimatedCard   | 進場改為 220ms、最多 150ms 錯開；減少動態或偏好中途切換時立即呈現。卸載停止動畫，已呈現內容不因設定關閉而重新消失。                                                                |
| Toast / Snackbar    | 完整訊息、獨立操作區與至少 44px 關閉控制；只有堆疊最上方、前景可閱讀時間才計時，捲動、輔助閱讀與互動期間保留。動作通知及需捲動的長文預設等待操作。新通知以獨立 ID 隔離舊關閉回呼。 |
| Web PageLoadingCard | 地圖、共用頁面、課程、登入確認與助理使用同一個等待提示；原本的情境文字保持可見，只宣告一個禮貌狀態，不捏造進度百分比。                                                             |
| WorkspaceList       | 組字中的 Escape 交給輸入法；一般 Escape 保留原清除語意。清除搜尋或返回全部課程後，焦點回搜尋欄。                                                                                   |

## 驗證與邊界

- 課程搜尋測試先以原版重現三種組字 Escape 與兩個焦點遺失案例，再驗證修正；校園、待辦、篩選、hash 與 history state 都保留。
- 原生抽屜測試檢查真實導航呼叫，包含快速連點、取消、過期動畫、旋轉、偏好切換、身分變更及舊登出確認。
- 通知測試使用可控時間、AppState 與 AccessibilityInfo，檢查背景時間、堆疊閱讀、焦點、讀屏設定、雙點及 Snackbar 置換。
- 共用元件回歸檢查處理中標籤不卸載、禁止重送、恢復可按、動態取消及已呈現卡片不重播。
- 既有 Interface Design Browser 加入真實 PageLoadingCard / CSS，檢查 320px、390px、桌面、深色、200% 文字、站內大字、系統與站內減少動態。來源雜湊、量測與截圖隨 workflow artifact 保存。
- 元件測試、Chromium 畫面、iOS 模擬器及實體裝置是不同證據；本文件不將模擬事件當作 Safari 注音、VoiceOver/TalkBack 或正式帳號的真機驗收。

本輪不變更 API、資料權限、正式資料或套件版本。合併依儲存庫必要檢查與審查流程辦理；正式發布須以發布結果另行確認。
