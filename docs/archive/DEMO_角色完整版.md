## 推薦 demo 走法（5-7 分鐘）

口試委員想看「校園多角色 + 同一資料貫穿」的完整故事：

1. **進站** → `/login` → 點「👩‍🎓 學生」→ 跳 `/timetable`
2. **學生看課表 → 點資料結構** → `/course/c1` 看到教材、作業、測驗（完整 demo workspace）
3. **同一門課切換到教師端**：右上角身份膠囊 → 點「🧑‍🏫 教師」→ 自動跳 `/teacher/course/c1`
4. **教師端展示**：點名、成績冊、題庫、測驗、Rubric 都能進
5. **再切換到 TA**：紫色 banner 出現，「教材單元」「題庫」變灰色 → 證明權限有差異
6. **切換到「🎯 社團幹部」** → 跳 `/clubs` → 上方綠色管理區出現
7. **切換到「🏛️ 系主任」** → 跳 `/admin` → 看到 3 件待審公告，點「核准」變綠 ✓
8. **切換到「🛡️ 管理員」** → 同 `/admin` 但多出使用者管理 + 系統設定
9. **切換到「🎓 校友」** → 回首頁 → 灰色 banner「僅可瀏覽」；點社團「加入」彈 toast「校友身份僅可瀏覽」
10. **最後到 `/settings` → 登出** → 真的跳回 `/login`，故事閉環

## demo 當天注意事項

- 角色切換靠 **localStorage**（key: `demoRole`），不需要 Firebase
- 第一次打開時若沒切過身份，預設是 **訪客**
- 右上角膠囊會顯示「目前角色 · 對應人名」，整個 demo 過程都看得到
- Firebase 配置可有可無：所有頁面都有 demoData fallback
- 結束 demo 想清狀態：DevTools → Application → Local Storage → 刪 `demoRole`
