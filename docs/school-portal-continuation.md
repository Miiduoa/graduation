# 校務瀏覽器連續匯入與草稿保留

延續 PR #290；未新增另一套登入或資料儲存服務。

## 修正的操作斷點

原先只有 browse 階段渲染 WebView，擷取表格後會卸載。選表格／核對期間校方網頁因此消失；想再匯入只能重新載入入口。本版從本人明確同意開始，到關閉或帳號／校園改變為止，保持同一個 WebView 與穩定 source。在 choose、review、done 隱藏畫面並停用觸控與輔助使用者介面，不將核對流程誤當成新登入。

- 核對時可回校方頁面，再繼續同一份草稿，保留修正文字、學期與排除列。
- 重新擷取前確認是否取代草稿；只有成功取得並解析新表格才替換，失敗不清除原稿。
- 成功儲存後可繼續匯入其他學期，或接著匯入課表／成績，不重建瀏覽器。新批次清除前一批的學期、排除列、撤回確認與 batch ID。
- 關閉按鈕與原生返回都檢查未儲存草稿；已開始的儲存不可被返回鍵中斷。
- 校園／帳號變更優先卸載，不等待草稿確認。回核對、關閉提示、離開前景會撤銷擷取請求，晚到訊息不覆寫草稿。
- 瀏覽器程序中斷不刪除已擷取的草稿。明確重新載入會重建瀏覽器但保留可恢復的草稿；校方可能要求重新登入。

## 不變的邊界

沒有讀取密碼、Cookie 或網站 storage，沒有新增網路攔截、登入繞過、校務背景排程或自動儲存。保持 incognito、非共享 Cookie、HTTPS 校園來源白名單與擷取 nonce 驗證。隱藏／背景時不接受新的頁面導覽、新視窗或擷取訊息；不宣稱因此阻止校方頁面所有內部腳本或子資源活動。關閉後卸載 WebView，不宣稱已實測每種 OS Cookie 實體刪除。

保留同一個原生元件是程式層級的生命週期修正，不保證學校 session 永不到期。實際六校登入、WebView 隱藏／恢復、iOS／Android Cookie 生命週期及大型字型仍需真機驗收。

## 測試

新增 SchoolPortalSession.test.tsx 的 17 個案例，包含元件建立／卸載次數、核對與返回、跨學期與跨類型連續匯入、未儲存關閉、原生返回儲存鎖、草稿替換失敗、瀏覽器程序中斷、帳號隔離及批次撤回。

專項 CI 保留原有全部 Web 擷取、原生匯入和登入測試，額外納入新檔。執行結果以對應提交的 CI／JSON artifact 為準。Mock WebView 的測試不等於真實校務帳號或手機 Cookie 驗收。此功能仍在 PR #290 分支，不代表正式網站或 App 已部署。
