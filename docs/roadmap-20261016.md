# Campus One 未完成功能清單

日期：2026-10-16。對照目前 main 的網頁、手機與後端，只寫還沒做完、只有殼、或面試現場會踩到的缺口。沒有授權改正式資料庫、也沒有要部署。

線上點餐維持關：正式環境不要設 `ONLINE_ORDERING_ENABLED`，網頁不要設 `NEXT_PUBLIC_ONLINE_ORDERING`。

工作量只講範圍，不估日曆時間。

- **小**：幾個檔案就能接上或補資料
- **中**：一條完整切片（畫面 + 資料 + 測試）
- **大**：要跨網頁／手機／後端，或真的去對各校來源
- **很大**：平台級（學校登入、LMS、金流、IoT）

排序依 10/29 成大、11/6 北大面試示範：先能讓委員切到該校、看到課表、點名、公告、社群、餐廳，再排地圖交通與其他殼。

---

## 1. 匯入課表

- **現在狀態**：網頁 `/import`、手機 `PersonalImportScreen` 都能從文字、CSV、截圖（裝置內 OCR）做出個人課表草稿，確認後才寫入。資料留在這台裝置，不跟雲端同步。靜宜節次對得上格狀課表；成大／北大目前沒有自己的節次表。
- **還差什麼**：成大、北大的上課節次對照；週格截圖的幾何辨識；PDF／XLSX；從學校系統「帶入課表」（學號登入沒開就走不通）；雲端備份仍顯示還沒接通。
- **工作量**：面試用貼上／截圖示範是 **小**；各校節次 + 學校帶入是 **大**。
- **面試**：這是現在就能演的主軸。準備一張成大、一張北大真實課表，預留手動改節次的時間，不要承諾「截圖一定一次成功」。

## 2. 簽到點名

- **現在狀態**：後端 `startLiveSession`／`joinLiveSession`／`endLiveSession` 已上。網頁課堂點名、手機教師今日「開始點名」會開 10 分鐘 QR。學生端支援 QR、數字碼、地理圍欄。老師開點名會檢查授課身分、重試鍵跟帳號範圍。
- **還差什麼**：網頁在學號登入沒開時會寫「這個功能還沒接通」。自拍活體明確不支援。成大／北大要有真實課班成員與老師／學生帳號，不能只靠舊 demo UID。裝置上老師開、學生掃的整段還沒當面試腳本驗過。
- **工作量**：**大**（帳號 + 課班 + 兩台裝置）。
- **面試**：有學校帳號與課班就演 QR；沒有就從腳本拿掉，不要用訪客硬演。

## 3. 校園公告

- **現在狀態**：網頁 `/announcements`、手機公告總覽都讀 `schools/{schoolId}/announcements`。目錄裡已有成大、北大的官方列表網址。排程每天台北 07:00、11:30 跑兩次，目前只同步 **靜宜 `pu`**。沒資料時會說來源還沒接上，不會拿過期快取假裝有新稿。
- **還差什麼**：核准後才寫入成大／北大 Firestore；用真實 HTML 驗證解析器（成大 iWeb、北大 cms）；來源掛掉時的「暫時抓不到」。
- **工作量**：**大**（每校爬蟲品管 + 寫入核准）。
- **面試**：委員一切換成大／北大，空牆最減分。這是資料面最急的一項。

## 4. 餐廳資訊

- **現在狀態**：網頁生活／餐廳、手機用餐頁可讀公開目錄。靜宜有核過的菜單。沒資料時寫「這間學校的餐廳還沒上架」。自己的線上點餐、付款、取餐號都關掉。
- **還差什麼**：成大、北大的地點與菜單（只展示或外連店家自己的訂餐頁）。不要打開 `native_order`。
- **工作量**：整理公開資料 **中**；要商店家審核與外連是 **大**。
- **面試**：切學校後要看得到店名，不是空目錄。有人問「能點餐嗎」就明說：現在只看資訊，自己的點餐沒開。

## 5. 社群

- **現在狀態**：網頁 `/community` 有動態、看板、打卡、學伴，要登入。手機 `CommunityScreen` 有對應交流。手機「社團」入口是殼：申請與名單管理尚未開放。
- **還差什麼**：成大／北大看板與貼文種子（示範用、非正式正式資料庫授權就不要寫正式庫）；手機社團申請／幹部名單；沒有學校成員的一般帳號私訊還在設計、沒做。
- **工作量**：網頁示範種子 **中**；手機社團正式做完 **大**。
- **面試**：走網頁校園交流。手機不要點進「社團」，會撞上殼。

## 6. 學校登入（學號／SSO）

- **現在狀態**：Google／平台帳號可用。學號登入看 Nuni `sign-in-options`，沒開就隱藏。網頁不少功能（點名、好友空堂、成績）會直接說還沒接通。各校 adapter 還在研究文件，沒做成 nuni-api。
- **還差什麼**：成大、北大各自的登入接法、失敗分類、不在客戶端存校務密碼。
- **工作量**：**很大**。
- **面試**：不要承諾「用成大學號登進去」。用平台帳號 + 本機課表 + 公開資訊。

## 7. 公車與即時交通

- **現在狀態**：TDX 查站的客戶端在。成大對到台南；**北大沒有城市對應**，會顯示附近站牌尚未啟用。到站時刻還沒用真實站牌核過。
- **還差什麼**：北大北北基城市與站牌；成大站牌對真實 TDX `stopId`；示範環境的憑證與資料。
- **工作量**：城市對應 **小**；核實站牌與到站 **大**。
- **面試**：11/6 北大通學會被問。沒站牌就不要打開這頁裝忙。

## 8. 校園地圖與 AR

- **現在狀態**：地圖讀各校 Firestore 地點；沒有就連校方地圖。AR 步行路網目前只有靜宜；其他學校會明說尚未提供 AR，不會生假路。室內地圖也偏靜宜。
- **還差什麼**：成大、北大的地點種子；AR 路網是另一件事。
- **工作量**：地點 **中**；AR **很大**。
- **面試**：地圖瀏覽可以演。AR 不要在成大／北大硬開。

## 9. 私訊

- **現在狀態**：已加入學校課班／群組的人可以私訊。規則認 `schoolId` 與成員資格。
- **還差什麼**：一般 Google／訪客帳號的聊天、訊息邀請、平台封鎖整套都還沒做。
- **工作量**：**很大**。
- **面試**：沒有課班成員就不要演聊天。

## 10. 線上點餐與商家接單（維持關閉）

- **現在狀態**：點餐、訂單、商家工作台程式都在，但正式開關是關的。網頁「我的訂單」寫目前還不能線上點餐。手機未綁店顯示還沒接到訂單系統。TapPay／LINE Pay、商家菜單管理、營收、忠誠都是尚未開放。
- **還差什麼**：面試不需要把點餐做完。要演餐廳就補目錄與外連。正式環境繼續不要設點餐開關。
- **工作量**：口頭與文案 **小**；外連網址 **中**。
- **面試**：被問就說政策上沒開，不要切到商家接單頁。

## 11. 共同空堂與課表分享

- **現在狀態**：網頁課表有分享與約空堂 UI。沒有學校帳號就擋住，課表仍可在這台瀏覽器編。
- **還差什麼**：學校帳號、好友關係、可示範的同學帳號。
- **工作量**：**大**。
- **面試**：可以秀本機課表；不要走到分享連結失敗。

## 12. 圖書館

- **現在狀態**：成大、北大都有官方館藏／借閱外連。
- **還差什麼**：App 內登入續借。用本機假續借充當真實借閱不誠實。
- **工作量**：外連示範 **小**；真的接 OPAC **大**。
- **面試**：打開校方圖書館即可。

## 13. LMS／TronClass 深度課務

- **現在狀態**：手機 LMS v2 畫面多數要開發用 demo session。正式深連結會說課程功能尚未開放。TronClass、課程顧問偏靜宜。作業線上繳交是殼。
- **還差什麼**：成大／北大正式課務、繳交、成績發布整條。
- **工作量**：**很大**。
- **面試**：不要進 CourseHub v2 或 TronClass。

## 14. 宿舍與洗衣

- **現在狀態**：手機宿舍入口是殼。開發 demo 裡有模擬洗衣，會標示範。
- **還差什麼**：真實設備與成大／北大宿舍資料。
- **工作量**：**很大**。
- **面試**：跳過。要提住宿就連校方住宿網頁。

## 面試前建議順序

1. 成大公告同步與餐廳／地圖地點（沒有寫入核准就不要寫正式庫）。
2. 北大做同一套，並補交通城市對應。
3. 準備成大、北大課表匯入示範（含手動改節次）。
4. 點名只在有老師／學生課班時列入腳本。
5. 社群走網頁；手機社團、宿舍、商家接單、LMS 不要點。
6. 點餐開關維持關。

示範時可以打開：選學校、匯入課表、公告（有資料才行）、餐廳目錄（有資料才行）、網頁社群（有看板才行）、圖書館外連、地圖瀏覽（有地點才行）。
