## 本次行為

- 顯示原始教材文字及 PDF 頁碼，以最多 1,600 字元的完整片段閱讀。
- 一般閱讀「上一段／下一段」會接續走到相鄰可讀 PDF 頁的末段／首段，跳過無可讀文字的頁面但保留原有缺頁警示；頭尾不循環，跨頁不清除原段筆記、讀法或講解，切換時仍會取消未完成的推論。從逐題練習回到原文、用段落按鈕翻頁／跳待複習段時會把鍵盤焦點移回目前段落起點，讓讀屏與手機鍵盤使用者知道已到哪一頁；更改讀法下拉選單時仍保留選單焦點。
- 可選理解概念、考前複習、練習思路。模式只影響明確啟用後的 AI 提示。
- AI 提供本段講解、逐字引用與一題自我檢查。先輸入自己的想法，再展開參考回答。
- 切換段落或閱讀模式後，回來仍能看到個人筆記、問題草稿、成功的講解與各次試答。
- 每段可自行加入待複習清單，再從清單跳回原頁／原段。新增「上一個／下一個待複習」跨頁循環導覽，未標記的目前位置也能依教材順序找下一段；清單只由使用者決定，切換不會自動移除標記或評分。
- 每段、每種讀法保留最近 6 次成功講解，可選取舊講解繼續追問。失敗、停止或取消不會抹掉舊內容。
- 待複習段落若在目前讀法已有自我檢查題，可開始一輪逐題複習，先獨立作答，再核對參考回答與教材。由本人選擇「這題已理解」或「還要加強」，也可略過、回看或重練待加強題。
- 追問最多帶入同段、同讀法的最近 2 輪；選舊講解時只沿著該次對話接續，不混用另一條追問分支。
- 引用必須確實出現在該段來源。這項檢查不代表生成的解釋或算式一定正確。
- 可在本段原文看到 AI 引句的逐字標記，點「定位原文引句」回去核對；三步卡片依序呈現教材引用、AI 解讀與個人試答。若相同引句重複出現會提示目前標記第一處。這是對照流程，不是數學推導或自動正確性驗證。
- 新講解可包含 2–4 個獨立步驟，以「上一步／下一步」或步驟清單切換。每一步有自己的說明與逐字引句，原文標記跟著目前步驟更新；「定位這一步的原文」將焦點移到該引句，本機朗讀也跟隨這一步。
- 教材內的基本公式可排版顯示，並保留原始公式文字供核對。公式必須逐字存在於該步引句；這項功能只處理呈現，沒有數值求解或推導正確性判定。
- 可主動下載本次筆記為純文字檔，包含原頁碼、原文、個人筆記、講解與試答；只有已試答且已展開的參考回答才會匯出。
- 可儲存完整閱讀進度，關閉後再從本機進度檔還原原頁段、讀法、筆記、講解、試答與問題草稿。逐題練習中也可另存包含閱讀進度與本輪自測狀態的 JSON；載入先顯示預覽，確認後才取代目前內容。
- 支援瀏覽器語音輸入與可用時的本機中文朗讀；語音輸入不會自動送出。
- 沒有 WebGPU 或本機中文聲音時，原文閱讀仍可使用。

沒有正式評分、成績寫入、作業送出或教師進度變更。白板內容只保留在目前頁面的記憶體，
不寫入 localStorage、資料庫或學習計畫。關閉／離開白板、換教材或帳號界線變更會清除本次會話；
使用者可明確下載文字筆記或閱讀進度檔，由自己保管。每段筆記與每次試答各最多 2,000 字元。
需要再生成時沿用裝置模型快取。自動保存、雲端同步與自動錯題判定尚未實作。

## 待複習的逐題練習

在待複習清單按「開始逐題複習」，會依教材原頁與段落順序，取出目前讀法、目前選取的成功講解中的題目。
每個已標記段落最多取一題；沒有題目的段落會明示數量，不會借用其他讀法或另一條追問分支。
開始練習不會下載或啟動模型；已還原的題目也能在沒有 WebGPU 的裝置閱讀與練習。
進入練習會卸載原講解畫面並取消其未完成生成，晚到的講解不能改變這一輪題目快照。

新一輪使用獨立且空白的試答與揭答狀態，即使原講解已作答或展開答案，也不會提前帶入。
每題最多 2,000 字元，當輪有非空試答才可「對照參考回答」，修改試答會重新隱藏答案並清除該題自評。
「查看原文提示」是明確操作，會展示該題教材及精確引句；「回白板看這段」會暫停這一輪並回到正確原頁／段，保留原讀法、原題號、草稿、提示與自評。在原文頁可選「繼續這輪練習」回到原題，或明確結束暫停的練習。

一輪有明確終點。到最後一題後顯示本人自評、還要加強、略過及未完成的題數，不提供正確率或 AI 掌握度判斷。
可以從摘要回到任一題，也可以重練本輪全部或尚未自行標示理解的題目。
逐題畫面提供獨立的「上一題／下一題」：這只是切換查看位置，不會把還沒回答的題目誤當作「略過」或完成，自評與草稿原樣保留；最後一題的「下一題」會停用，真正要標記略過仍須按「略過這題」。這讓學生在手機上可先瀏覽所有題目，再決定答題順序。
重練待加強子集後，「重練本輪全部」仍能回到開始練習時的完整題組；即使還原的是待加強子集備份，也會由已核驗的教材與講解重建原始題組，不需要離開白板重新開始。全部重練會清空這一輪試答與自評，想保留舊內容請先下載。
練習、略過、結束和重新練習都不覆寫原講解的試答、答案展開狀態、筆記或待複習標記。

本輪題號、試答、提示、揭答及自評均保留在白板記憶體中，可主動「下載本輪練習」為純文字紀錄，或「儲存練習與閱讀進度」下載可續接的 JSON。
手機瀏覽器也提供明確按鈕「複製本輪紀錄」，使用裝置內建剪貼簿 API 複製與文字下載相同的內容，不會自動上傳。沒有支援／拒絕剪貼簿權限時，除了顯示錯誤與保留當輪試答，還會在明確點擊後提供唯讀文字框，供手機長按選取、手動複製；仍可改用 TXT／JSON 下載。手動複製區域與唯讀文字框使用不同且清楚的無障礙名稱，避免讀屏與測試把兩個控制項誤認為同一目標。文字框只包含點擊當下的答案揭露狀態，修改試答、換題、重練、回原文、換教材或還原會清除，逾時的剪貼簿失敗也不能把舊紀錄重新顯示；不使用 execCommand 及不新增任何網路請求。剪貼簿內容可能被其他 App 讀取，操作前請注意個人資料與貼上位置；這不是加密或雲端保存。
剪貼簿紀錄的參考回答仍只有本輪有試答且當下展開才會包含；沒有啟動模型，未新增依賴或收費服務。此為模擬瀏覽器測試的功能，iOS Safari／Android Chrome 實機授權、複製、貼上與檔案下載仍需驗收。
紀錄保留題目順序、原文位置、讀法、獨立試答及本人自評；只有當輪已試答且仍展開的參考回答才會匯出。
原文提示是否展開按目前狀態記錄，不宣稱學生從未看過提示。題目與參考回答仍可能有誤，需對照教材。
返回閱讀時先暫停練習，不會清空本輪回答；此狀態只保留在當前分頁，原閱讀進度檔不包含練習。暫停時可明確下載完整練習與閱讀進度 JSON，開始新一輪練習會取代暫停草稿，因此會在暫停區顯示提醒。新一輪、明確結束、關閉白板或更換來源前，需自行備份想保留的內容；不會背景自動保存。

原有閱讀進度仍使用 v2，沒有新增練習欄位，本輪草稿也不寫進一般閱讀進度檔或覆蓋先前試答。新增的練習備份使用獨立格式 campus-one-study-practice v1，內嵌原版 v2 閱讀進度與當輪練習狀態。
練習期間可下載純文字練習紀錄或完整 JSON 練習備份；回到閱讀後恢復原本的保存進度與筆記下載。載入 JSON 時會核對帳號與課程、驗證原文引句、教材段落、目前模式的題目及自評狀態，不能加入不存在的題目或提前揭答；還原後仍是本人自評，不會自動評分。
備份如標示「本輪結束」，最後一題必須確實留下本人自評或略過紀錄；若只有偽造的結束旗標、缺少最後一題處理結果，會拒絕載入且保留目前工作階段。已結束後主動返回題目會改回進行中，仍可正常保存。
本機檔案讀取中暫時隱藏練習，取消、失敗或取消還原預覽會保留整輪狀態；成功換教材、確認還原或換帳號／課程則清除。
教材櫃重新整理、session context、角色、封存狀態變更及離開白板會卸載工作階段，不能用舊回應恢復本輪內容。

## 保存與還原閱讀進度

「儲存閱讀進度」會下載 `.campus-study.json`，即使還沒有筆記也能保存目前閱讀位置。
之後在同帳號、同課程的白板展開「接著上次的進度」，選擇檔案；程式先驗證內容，
預覽教材名稱、原頁段、讀法及筆記／待複習數量。按「還原這份進度」才會替換目前白板，
也可以取消，或先儲存正在閱讀的內容。

進度格式為 `campus-one-study-progress`，新保存使用第 2 版，最多 8 MiB，仍可載入原先的第 1 版。
第 1 版維持原本的五欄講解格式；第 2 版接受舊講解或含 `steps` 的新講解。舊檔再次保存會升級為第 2 版，
不會為舊講解捏造步驟。分步講解與原文公式會完整存入進度檔及文字筆記；步驟導覽本身從第一步開始，
不把當下步驟索引寫入檔案。只保存穩定的
`platformAccountId` 與 `workspaceId` 供載入時核對，不保存 session context、登入 token、cookie 或權限判定。
載入時仍需通過當下課程存取流程；不同帳號／課程、未知版本、損壞格式、超限內容、錯誤段落位置、
孤立的狀態 key、不合法的追問祖先與無法對照原文的 AI 引用都會拒絕，不清空目前內容。
檔案也保存各頁的分段長度，還原時逐段比對；日後若切段方式改變，會明確拒絕不相容的對應，避免把筆記移到錯誤段落。
成功還原建立新的本機 revision，不沿用檔案中的執行狀態，也不自動啟動模型或朗讀。

檔案保留教材副本，因此會明確提示對照課程最新內容，不把還原內容描述為剛從 LMS 取得。
進度檔未加密，包含個人筆記、問題草稿、完整講解及練習參考回答；帳號／課程核對是防止誤載，
不是檔案加密或來源認證。還原會維持答案原本的展開狀態，JSON 本身不作為保密題庫。
純文字筆記仍只匯出已試答且已展開的參考回答。

載入進度與讀取新教材共用取消控制：停止、關閉、換帳號、換課程及權限撤銷後，
晚到的檔案讀取結果不能建立預覽或替換目前內容。預覽期間更換教材會移除舊預覽。

## 來源界線

`CourseMaterials` 只傳入當次已取得權限的教材正文。教材內的 URL 仍是文字，
不會自動下載附件、探查外站，或將教材描述當成附件內容。

PDF 沿用 `readPersonalImportDocumentFile` 的同源讀取器：最多 8 MiB、20 頁，
保留原始頁碼、OCR 與缺頁警示。公式、表格與圖像仍需對照原檔；辨識出的文字不代表理解圖表。
文字總量最多 60,000 字元，超過時要求拆分，不會默默截掉內容。

換帳號、session context、課程、角色或封存狀態時，父元件的 key 會重建整個閱讀工作階段。
重新讀取課程教材時會先關閉白板，401／403／404／410 存取失效後不得重開舊內容。
選新檔、切段、切模式、停止或收合會取消相應工作，晚回應不會寫入新工作階段。
保留資料以來源 revision、頁面／段落位置及閱讀模式區分；即使新 PDF 檔名與頁面 ID 完全相同，
成功更換來源也會重設整份會話。匯入取消或失敗則保留原教材與既有筆記。
模式間共用個人筆記與待複習標記，問題草稿、講解、試答與答案展開狀態分開保存。
下載只在使用者按下按鈕後建立本機 Blob，沒有上傳；來源更換、下一次下載與關閉時釋放先前 URL。

## 裝置端講解

`studyTutorRuntime.ts` 沿用既有 `personalImportAi.worker.ts` 的生成介面與固定模型版本。
每次傳入目前的一段、模式、最多 500 字元的追問，以及符合預算的近期同段對話，不提供工具呼叫。
歷史 envelope 必須與目前段落 ID、完整原文及模式完全一致，每個歷史回覆也再次通過 schema 與引文驗證。
歷史 JSON 最多 2,200 字元、完整 prompt 最多 5,000 字元；字元數不等於 token 數，worker 仍以真正 tokenizer 檢查 4,096 token 上限。
超出預算時只省略完整的舊輪次：兩輪放不下就帶最近一輪，最近一輪仍放不下則依原文重新整理並提示。
原文與這次問題不會默默截斷。可使用「只依原文重新講解」明確開始另一條講解。
Prompt 將歷史當作理解追問的資料，不把先前模型回答視為教材事實；新引文仍須來自原文。
講解可帶有 2–4 個 `steps`，每步包含 `title`、`explanation`、`sourceQuote` 與選填的 `formula`。
每步的引用必須是目前原文的連續子字串；公式則必須是該步引句的連續子字串。
不接受額外欄位、空步驟、不符引用或超限內容。舊五欄回覆仍可閱讀與追問，但不補造步驟。
步驟會完整計入既有歷史預算，超限時省略完整輪次；目前選取的步驟不會縮減模型可見的教材內容。
現有模型資源 GET 白名單、輸入／輸出 token 限制及 GPU tensor 釋放機制維持原樣。

只有使用者按下「啟用 AI 講解本段」才建立 worker。首次下載沿用現有約 1.9 GB 模型；
支援性檢查、下載、推論、格式錯誤或引文不符都會顯示失敗，不以預製講解冒充模型成功。
準備最多 10 分鐘、生成最多 120 秒。結束、錯誤、取消與逾時都會終止 worker。

朗讀只選 `SpeechSynthesisVoice.localService === true` 的中文聲音。
找不到時不改用遠端聲音。語音辨識沿用 `VoiceDictationButton`，可能使用瀏覽器的線上服務，
因此不能把整個語音流程宣稱為完全離線。朗讀時停用語音輸入，避免把播報聲錄成提問。

## 基本公式呈現

公式使用 [MathML Core](https://www.w3.org/TR/mathml-core/) 的分數、上下標與根號結構，不增加數學排版依賴。
目前支援數字、小數、單一英文字母／希臘字母、明確四則運算與比較符號、括號、`x^2`、`x_1`、
`x_{i+1}^2`，以及明確括住範圍的 `sqrt(...)`／`√(...)`。乘除由左至右，腳標先於乘除；
例如 `a/b+c` 會把 `a/b` 排成分數，再接 `+c`，不把 `c` 放入分母。

必須完整解析整條公式才排版：最多 200 字元、120 個語法 token、12 層巢狀。
LaTeX、隱含乘法、多字母函數、中文、缺漏括號或其他不支援的語法會保留全部原文，
不丟字、不猜測缺漏、不做數值求值。排版成功仍可展開「核對原始公式」，查看原始空白與符號。
資料只經過固定標籤的 React 元件，沒有 HTML 字串插入、程式求值或外部服務。
畫面提供可聚焦的橫向捲動區，實際字型、觸控與讀屏效果仍需在目標裝置驗收。

除了原本的 JSON 下載，閱讀、進行中的逐題練習及暫停中的逐題練習均可由使用者主動「複製…進度 JSON」。使用既有 v2 閱讀進度／v1 練習 checkpoint 序列化器，**複製內容與下載內容相同**，保留教材、原頁段、模式、筆記、講解、完整練習草稿與自評，沒有新增格式或背景同步。剪貼簿不支援或被拒絕時提供唯讀可選取的 JSON，供手機手動複製並貼到 UTF-8 純文字檔以 .json 副檔名儲存；編輯或離開練習後取消過期備援與晚到錯誤，不會自動外傳教材。JSON 可能包含完整私人教材及參考答案且未加密，應自行妥善保管。新增模擬 DOM UI 回歸及真實進度 parser 往返核對，仍非 iOS Safari／Android Chrome 真機測試；需檢查長文字、讀屏、權限拒絕、手機儲存 .json 與重新匯入。PR 維持 Draft，需完整 CI／CodeQL、App 審查、Maestro 和競品對測另驗。
