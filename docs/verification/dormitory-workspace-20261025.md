# 宿舍生活工作區｜功能與資料驗證

最後更新：2026-10-25

## 本次體驗升級

以「當下要辦什麼事」為主要入口，Web 與 App 共用同一套資料規則。

| 使用情境 | Web | App | 來源與限制 |
| --- | --- | --- | --- |
| 個人住宿資訊備忘 | 儲存、編輯 | 儲存、編輯 | 本機、依校園及帳號分區 |
| 住宿總覽與下一步 | 待辦摘要、快速操作 | 待辦摘要、快速操作 | 僅根據個人紀錄，不宣稱校方申請結果 |
| 校方住宿指南 | 公開房型、費用、電話、官方連結 | 同左，支援撥號 | 僅已核實的靜宜資料；其他校園顯示官方入口或缺資料狀態 |
| 重要日期 | 新增、修改、完成、刪除 | 新增、修改、完成、刪除 | 使用者自行輸入，不會自動推播或取代校方期限 |
| 設備問題 | 常見問題預填、新增、編輯、篩選與複製 | 常見問題預填、編輯、分享與狀態註記 | 個人備忘；沒有送往校方的報修回執 |
| 申請、入住與退宿 | 分階段準備清單 | 同左 | 勾選不代表完成正式程序 |
| 洗衣計時 | 自行估算、延長、清除 | 自行估算、延長、清除 | 非即時機台連線 |
| 切換帳號／學校 | 分區隔離與寫入前衝突檢查 | 同左 | Web localStorage；App AsyncStorage，未跨裝置同步 |

## 資料可信度

- 已核實：靜宜大學住宿服務組公開網站 https://osadorm.pu.edu.tw/ 、[官方房型及價位表](https://c032.pu.edu.tw/p/412-1065-1970.php?Lang=zh-tw)（查核日 2026-10-25）。
- 費用數字屬學期參考資料，不推斷有空床、可申請、付款成功或抽籤結果；宿舍收費可能隨學期更動。冷氣用電另計。
- 其他學校僅提供已核實的官方網站連結，**不**套用靜宜宿舍資訊或虛構聯絡方式。
- 日期由學生自行新增；介面不會宣稱自動同步校方公告或設定了系統通知。
- 個人報修狀態（尚未通報、已自行通報、已自行確認完成）與校方正式報修狀態明確分離。
- 清單、日期、計時與設備紀錄只保存在目前裝置，沒有備份或跨端同步；訪客切換登入帳號也不會自動搬移紀錄。
- 沿用既有 OLED / 淺色主題色票與 44px 觸控基準，小螢幕標籤改可水平滑動、支援鍵盤聚焦與無動效偏好。

## 待校方授權後才能做的事情

正式宿舍申請、身份驗證後的床位狀態、繳費對帳、校方修繕單號與雙向回覆、包裹物流、真實洗衣機使用情況，以及跨裝置同步均**尚未串接**。在取得資料授權及安全設計前，不用模擬數據冒充即時資料。

## 測試與驗收

新增 Web 日期操作及校園切換測試；共用資料模型針對日期格式、閏年、重複識別碼、筆數上限與舊版紀錄相容性測試；App 同步加入資料界線測試。

在完整工作區可執行：

```sh
pnpm --filter web typecheck
pnpm --filter web test --run
pnpm --filter web lint
pnpm --filter web build
pnpm --filter mobile typecheck
pnpm --filter mobile test --runInBand
pnpm --filter mobile lint
```

尚待實機核對：iOS / Android 鍵盤與安全區、大字體、VoiceOver / TalkBack、分享面板、撥號確認、手機瀏覽器無痕儲存及多視窗衝突處理。CI 尚未通過前不能宣稱正式可部署。
