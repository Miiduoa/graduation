# 個人資料匯入：實作範圍與驗證紀錄

更新：2026-10-14。這份文件記錄本次本機修改；測試通過不代表已部署、已上架，或已完成全部產品功能。

使用者不必提供學校帳密，就能從自己持有的文字、檔案與截圖建立個人資料。Web 與 Mobile 共用解析及驗證規則，資料仍各自存在使用中的裝置。

## 已實作的三類資料

| 類型 | 可核對內容 | 使用位置與界線 |
| --- | --- | --- |
| 課表 | 課名、學年度、學期、課號、教師、班別、星期、節次或時鐘時間、教室 | 匯入紀錄及個人課表。靜宜週一至五、有效節次可放入既有格狀課表；其他學校與特殊時段保留在個人紀錄，不硬套靜宜節次。 |
| 成績 | 課名、學年度、學期、課號、教師、學分、成績 | 成績頁的個人紀錄。自行輸入不構成學校正式成績、校籍證明或畢業資格判定。 |
| 行事曆 | 名稱、日期、起訖時間、地點、全天及結束日期 | 個人行事曆。支援文字／表格及非重複 ICS 活動；不會因此建立老師發布的作業或完成繳交。 |

主要程式：`packages/shared/src/imports/`、Web 的 `/import` 與 `PersonalImportCenter`、Mobile 的 `PersonalImportScreen`。課表、成績及行事曆均有入口或匯入資料呈現。

## 輸入與辨識

| 項目 | Web | Mobile |
| --- | --- | --- |
| 截圖 | PNG、JPEG、WebP；單張 10 MB、2,400 萬像素內 | PNG、JPEG；單張 8 MB、2,000 萬像素內 |
| 文字檔 | TXT、CSV、TSV、ICS；400 KB 內 | TXT、CSV、ICS；512 KB 內，文字不超過 100,000 字元 |
| 其他入口 | 貼上文字、拖曳檔案、手動新增 | 貼上文字、選檔／相簿、手動新增 |
| 辨識執行 | 瀏覽器 Tesseract worker，繁體中文與英文 | App 內 WebView 的 Tesseract，繁體中文與英文 |
| 保存後整理 | 編輯、單筆刪除、撤銷最近新增批次、按類型匯出 CSV | 編輯、需確認的單筆刪除、撤回最近匯入批次、按類型分享 CSV；須在系統分享介面另行存檔 |

共用解析器最多接受 200,000 字元、500 筆輸入；用戶端可採更小限制。Web 另限制同一帳號／校園的本機匯入紀錄最多 2,000 筆。

辨識只讀取文字，再依有標題的表格或明確欄位解析。圖片中的週格座標、合併儲存格與色塊位置尚未解析；讀不準時需修正原文或手動填欄位，不能宣稱任意課表截圖都能自動完成。

Web 保留暫時原圖供核對；兩端保留解析來源文字及行號。圖片不作為匯入紀錄永久保存。兩端都有取消、逾時與錯誤狀態；舊工作完成時不能回填到已切換的帳號／校園。

OCR 在裝置執行，目前程式路徑沒有把截圖送往校務或雲端辨識 API。辨識程式、核心與繁中／英文字庫由本站（Web）或 App 內檔案提供，不再向外連線下載。

## 確認、儲存與課程連結

1. 選擇資料類型及校園；課表／成績補齊學年度與學期。
2. 讀取內容後逐筆修改，或取消勾選不想匯入的資料。辨識與預覽不會直接寫入。
3. 缺少必填值、無效日期／時間、錯位表格、跨校資料等錯誤會阻止保存；不猜填缺少的時段、學分或成績。
4. 確認後以新增方式寫入，保留既有紀錄。重複匯入會略過相同資料；成績／學分或名稱／地點／課班連結有衝突時要求核對，不能悄悄覆蓋或丟棄差異。
5. 寫入失敗保留草稿與原資料。Web 使用 Web Locks 保護同來源分頁的讀取／修改／寫入；Mobile 依儲存範圍序列化操作。編輯時檢查原紀錄版本，拒絕覆蓋已變更資料。
6. 撤銷只移除該批新增且未再編輯的紀錄；後來新增或修改的內容保留。Web 的撤銷入口保留於本次頁面狀態，Mobile 的批次歷史另存於本機。

儲存範圍分成平台帳號、學校帳號或訪客，再按校園區分。Web 使用 localStorage；Mobile 使用 AsyncStorage。登入同一帳號不會自動讓兩端資料同步，清除瀏覽器／App 資料或換裝置也不會自動復原。

課程連結只能手動選擇目前帳號已加入的有效課班，儲存前再次檢查可用清單。它只是個人紀錄的連結，不會自動加入班級、驗證老師身分、授予學籍或寫入正式成績。共用核心的可信課程比對規則也不把上傳內容當成可信目錄。

匯入資料不自動分享給好友或學校，也不寫入舊課表的雲端分享資料。既有手動課表與匯入課表按學期區分，學期未填或不同學期時不直接混排。

ICS 以台灣時間呈現，可處理明確的 `Asia/Taipei`、UTC 及全天日期；全天結束日期是「不包含該日」。未指定時區會提示核對。其他時區、重複規則／例外日期、取消活動、格式矛盾等會阻止直接保存，避免少匯入發生次數或寫入錯誤時間。

## 明確限制與後續產品工作

- 本次資料只存本機；雲端備份、帳號間搬移、Web／App 雙向同步與完整復原流程待做。
- PDF、XLSX 不直接解析；先匯出文字／CSV 或截圖。Mobile 的 CSV 匯出與逐筆刪除屬尚未合併部署的候選版本，需通過 CI 和實體裝置分享測試。
- 尚無週格圖片幾何解析、多頁教學大綱理解、輪替週、自訂校園節次設定或重複 ICS 展開。
- 個人事件不是完整作業／考試管理；提醒排程、繳交回執、官方來源持續同步仍須實作及驗證。
- 其他校園服務仍須按學生、教師、店家等真實角色驗收送出、收到、處理、取消、錯誤恢復及權限，不能從匯入功能推論全部完成。

競品研究顯示「截圖匯入」已是基本能力。本次優先補上能核對、避免覆蓋與可復原的流程，尚無證據宣稱全面超越競品；後續應用真實去識別樣本衡量辨識率、校正時間與回訪使用率。

研究核對的是官方公開資料，未登入競品驗證辨識準確率：

- [北科盒子版本記錄](https://apps.apple.com/tw/app/id6753217696)：匯入前可編輯、課表分享及多教室處理；[隱私政策](https://ntutbox.com/privacy/)說明裝置資料與分享範圍。
- [Unigent](https://www.unigent.tw/)：課表、待辦、學期行事曆與小工具，作為日常使用體驗參考。
- [MyStudyLife](https://mystudylife.com/tour/)：照片／PDF、確認匯入、輪替週及跨裝置；[支援文章](https://care.mystudylife.com/en/articles/9502590-adding-your-timetable)與現行功能頁對辨識器的輪替週支援敘述仍需實測釐清。
- [Shovel](https://shovelapp.io/) 與 [Canvas 匯入說明](https://help.shovelapp.io/en/connect-school-system/connect-canvas-to-shovel)：教學大綱、LMS feed、選課程、合併及同步，是後續作業／期限管理的比較基準。

## 行動端個人紀錄管理候選（尚未合併／部署）

Mobile 補上已存紀錄搜尋與分段載入、單筆刪除確認，以及以系統分享選單匯出當前類型 CSV；匯出前從持久層重新讀取，避免使用過期畫面快照。刪除使用紀錄版本核對與帳號／校園隔離，不可刪掉另一個畫面剛編輯的新版本。編輯或刪除一批的最後一筆時，清除不再可撤回的空批次。

Web／App 共用 UTF-8 CSV 欄位、引號處理與公式儲存格防護；匯出不含原始截圖、來源文字或批次資訊，並非可完整重建的跨裝置同步備份。分享面板關閉不等於使用者已儲存檔案；敏感成績可能交由選定的第三方 App 處理。正式發布前仍須驗證 Android／iOS 實體裝置權限、保存路徑、分享取消與重新登入隔離。
